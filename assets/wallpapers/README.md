# CiukiOS wallpaper tiles

`tiles/` contains three original, deterministic 8 × 8 pixel patterns created
for CiukiOS: Pacific dots, Slate linen and Warm weave. They contain no extracted
Microsoft or Apple artwork and no alterations of the approved Ciuki portrait.

The project dedicates these three patterns to the public domain under
[CC0 1.0 Universal](https://creativecommons.org/publicdomain/zero/1.0/).
See `LICENSE.txt`. Other wallpaper images are not covered by this dedication.

Public builds include these patterns instead of an empty wallpaper catalog.
`CIUKIOS_PERSONAL_WALLPAPERS=1` selects the owner's PNG/BMP files in
`third_party/win_bg/`; those files retain their own rights and are not included
in this public-domain dedication.
