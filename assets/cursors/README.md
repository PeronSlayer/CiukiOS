# Ciuki cursors

The active desktop set is **Ciuki**, original project artwork drawn by OpenAI
Codex for CiukiOS on 2026-10-22, under **GPL-2.0** (SPDX GPL-2.0-only; the
complete licence is the repository's `LICENSE`). The committed vector sources
are in `ciuki/*.svg`. They use the familiar macOS visual vocabulary of a black
arrow with a white outline and clear monochrome hands. No Apple artwork was
extracted, traced, copied or imported. The approved Ciuki portrait is unchanged.

The sixteen vector drawings cover arrow, busy, arrow+busy, I-beam,
not-allowed, four resize directions, move, pointing hand, crosshair, precision,
open hand, closed hand and help. Busy is a neutral segmented monochrome
indicator, not Apple's coloured wheel. These are static shapes, selected by
the existing desktop cursor API. Existing IDs 0–18 retain their meanings;
open hand, closed hand and help append IDs 19–21. The six existing Paint tool
drawings remain in `paint.h`, with their separate MIT notice.

## Deterministic conversion

`scripts/cursors/build_ciuki.py` produces `cursors.h` directly from the SVGs.
The header is committed and consumed by the normal build; no asset generator
or network access is needed at OS build time. Regenerate with:

```sh
python3 scripts/cursors/build_ciuki.py
python3 scripts/cursors/build_ciuki.py --check
python3 scripts/cursors/build_ciuki.py --check --sheet build/codex/f2-99-cursor-sheet.png
```

Reference toolchain: rsvg-convert/librsvg 2.63.3, cairo 1.18.6, Pillow 13.0.0.
Rasterisation uses a fixed 32x32 viewport, no fonts, external resources or
filters. Pixels with alpha >=128 are opaque; opaque RGB sums >=384 are white,
the rest black. Each SVG records its integer hotspot in `data-hot-x/y`.
`--check` compares all generated bytes with the committed header and catches
any toolchain rasterisation difference.

Both presenters use the same opaque and white masks, leftmost pixel in bit 31,
and subtract the same hotspot. Hardware uploads only black and white, using
the Savage's 64x64 AND/XOR pattern (unused pixels are transparent).
Software adds a shadow derived from the opaque mask: integer [1,2,1] x
[1,2,1] convolution, shifted (1,1), maximum opacity 80/255; opaque pixels
exclude the shadow. Bounds include that shadow within the 32x32 save-under.
Alpha blending is clipped to the damaged region; a stationary pointer is
untouched by unrelated damage. Client ARGB cursors keep their own alpha.
See `docs/validation/f2-99-cursors.md` for the hardware source comparison.

## Retained cursor schemes

`CURSORS.DAT` is the retained 16 by 16 scheme store made by
`scripts/build_cursors.py`. It is independent of the VMM desktop raster set.
Its Tango, Classic and 3D Contrast drawings retain their Public Domain
notices. The Tango scheme follows the Tango Desktop Project style guidance;
the icon authors and release notice remain in `assets/icons/`.
