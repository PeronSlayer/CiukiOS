# Adaptive wallpaper artwork

These three 1448×1086 RGB PNG siblings extend the scenery of the owner's
original Ciuk1, Ciuk2 and Ciuk3 wallpapers. The originals in the parent folder
remain unchanged. Created with the built-in image generation edit tool on
2026-10-08, following the owner's choice to extend scenery while preserving
proportions. Generation prompts and hashes are recorded in `generation.json`.

The composition leaves sky and foreground around the dog, lettering, mountain
lake and sunset. The desktop uses centered, aspect-preserving Fill, so those
elements remain visible on 4:3, 16:10 and 16:9 displays without bands. The
conversion to CWP2 preserves the adaptive PNG's RGB samples exactly; generated
artwork is not a pixel-identical copy of the original photograph/illustration.

These are wallpaper scene variants, not replacements for the approved Ciuki
portrait logo, runtime icon family or original boot photograph.
