# Native OpenGL for CiukiOS programs

CiukiOS uses TinyGL by Fabrice Bellard, Gek (DMHSW), and C-Chads.
The retained [licence](../../sdk/libgl/LICENSE-TinyGL.txt) requires this
acknowledgment in the product and documentation. The SDK installs that notice
in `licenses/`; the image ships it in `/system/licenses`. Graphics Demo also
displays the acknowledgment. There is no full OpenGL 1.1 conformance claim.

Since f7-14 `libgl.a` is the same GL engine the Win32 `opengl32.dll` builds
(`sdk/win32/opengl32`: engine, state, textures, pixel transfer, validation,
the bounded hardware journal, admission and census) over TinyGL's transform,
lighting and clipping front-end, the scalar software backend and the native
render3d provider (`native/provider.c`, sharing `provider.inc` with gdi32).
The engine files are LGPL-2.1-or-later (`licenses/opengl-engine-LGPL-2.1.txt`
in the SDK). TinyGL's own public names are renamed `tgl_*` inside the library
(`native/tinygl_rename.h`); `include/GL/gl.h` and `native/api.c` are
generated by `sdk/win32/opengl32/generate.py` from the opengl32 export tables.

`vendor/src` and `vendor/include` come from the supplied C-Chads snapshot.
`upstream.json` records original file hashes and the archive hash; `port.json`
records the reviewed local configuration and fixes. Altered files carry a
CiukiOS port note. No example, media, platform glue or prebuilt binary is used.

Include `<GL/gl.h>` and `<ciuki/gl.h>`, link with `-lgl` (and `-lm` outside the
SDK wrapper). Call `ciuki_gl_bind(pixels, width, height, stride)` before GL
commands, `ciuki_gl_finish()` before consuming visible pixels, and
`ciuki_gl_close()` on exit. Stride is in pixels. The library owns the depth
buffer; pixels belong to the caller. Packed targets render in place; other
strides use private rows copied out at finish. One thread and one context per
process are supported; target replacement retains GL state.

On a device whose render3d provider is qualified for the target, frames run on
the GPU; otherwise, and under `ciuki_gl_set_backend(CIUKI_GL_BACKEND_SOFTWARE)`,
they run on the scalar path. `ciuki_gl_status` reports GPU and CPU frames,
refusals and permanent fallbacks. Full-screen programs present a leased frame
with `ciuki_gl_present` after the desktop granted `DESK_LEASE`. Set
`CIUKI_GL_CENSUS=<frames>` in the environment to log the admission census.

The offline recipe in `build.py` is used by `sdk/build_sdk.py` and host tests.
It verifies every imported/ported source before compiling sequentially into
`libgl.a`. Headers are installed into the SDK sysroot. See
[the design and measurement record](../../docs/design/opengl-software.md).
