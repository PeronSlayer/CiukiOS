# G26 authored images

`g26-colours.jpg` and `g26-progressive.jpg` contain only a 16 by 16 grid:
the left eight columns are red (255,0,0), the right eight blue (0,0,255).
They are original CiukiOS test data, MIT. Neither contains a photograph or
third-party site material. JPEG compression can change a channel by a few
units; the oracle permits five units and requires opaque output.

Authoring recipe (Pillow is not a test dependency):

```python
from PIL import Image
data = bytes(c for y in range(16) for x in range(16)
             for c in ((255, 0, 0) if x < 8 else (0, 0, 255)))
image = Image.frombytes('RGB', (16, 16), data)
image.save('g26-colours.jpg', quality=100, subsampling=0, optimize=False)
image.save('g26-progressive.jpg', quality=100, subsampling=0,
           optimize=False, progressive=True)
```

PNG is generated by `raster_test.c` using the pinned existing PNG writer.
JPEG fixtures are retained to keep the decoder sanitizer test independent
of stb_image_write's JPEG encoder (whose signed shift trips UBSan).
