# 0.8.0 – 0.8.3: finestre DOS, app native, rete e browser

- **Data:** 2026-10-01 – 2026-10-05
- **Tipo:** retrospettiva / release
- **Versione/commit:** 0.8.0 (`4539d84`), 0.8.3 (`f3f9d7f`), fino a `a42a3b3`
- **Stato:** completato su Linux QEMU/KVM; hardware reale non qualificato

## Cosa è stato fatto

- **M4**: ogni finestra DOS possiede una VM; DOOM e due VM testuali passano.
  26/26 gate VM-window (su più esecuzioni seriali, non una sola continua).
- Nomi lunghi FAT16 (estensione LFN residente), CiukNote, CiukPaint,
  Device Manager, catalogo driver, impostazioni di rete.
- Windows 3.1 rimosso dall'immagine corrente.
- **CiukWeb**: browser nativo con HTML, immagini, e worker per CSS,
  TLS 1.2 (BearSSL) e JavaScript (mQuickJS); validazione end-to-end ancora aperta.
- TinyGL software, presentazione VirtIO-GPU 2D, rotellina del mouse,
  Display Properties con anteprima e ripristino automatico.
- Bundle portatile Windows e prerelease automatiche al push.

## Verifica

Gate a perimetro limitato su QEMU/KVM: DOOM a 34,78 loop/s, intervallo
massimo di presentazione 67,73 ms. Nessuna qualificazione su PC fisico.
