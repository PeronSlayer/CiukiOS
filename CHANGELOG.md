# Changelog

All notable project-level changes are tracked here.
This changelog is intentionally concise. Every completed task should update `Unreleased` unless the task cuts a release section.

## Unreleased

- Added native removable-media Files views for supported CD, floppy and BIOS-exposed disks: directory navigation, text preview, read-only notices, file import and graphical failure handling. USB currently requires BIOS exposure before boot; native host-controller hot-plug and writes to removable sources are not implemented.
- Extended Wallpaper to 99 indexed tiles with PNG/BMP conversion, append-only installation, graphical Refresh, persistent selection and preservation of the previous background after a malformed file. Default builds include three original CC0 patterns; owner-provided Windows wallpapers remain personal-build-only assets.
- Integrated Kenney Interface Sounds 1.0 under CC0, with the original archive, license, hashes and credits. Native ICH AC97 and supported Sound Blaster event playback, graphical previews/preferences and error paths run without leaving the desktop; event buffers/device state are released before DOS handoff.
- Fixed Ctrl/Space, right Ctrl, held chords and key releases in the cooperative Doom preview, using real-game recorded demo data for qualification. This is a source-port correction, not original DOS-binary virtualization. The existing restricted BIOS-text DOS window and silent cooperative graphics previews still do not implement arbitrary windowed DOS graphics, DPMI or audio devices.
- Moved console glyph scratch and shell history to bounded allocations while retaining the existing COM size guard. The selected September 26 native-desktop image (`08bc6df6510e55e3f501d49f9414e2d0f0a2006eccdda5dbf8f78bdc1e244bd6`) passes eleven focused QEMU Pentium III/128 MiB reports. It does not qualify physical T23/E500 hardware or repeat the entire historical compatibility matrix. See `docs/native-desktop-2026-09-26.md`.
- Made the native desktop, Setup and VGASETUP fluid: every framebuffer access now goes through a shared backend (`vbe_fb.inc`) that uses the VBE 2.0 linear framebuffer through short interrupt-free protected-mode bursts (no unreal limit survives a burst; banked access remains the fallback for V86, missing A20 or firmware without LFB). Under QEMU/KVM each former bank switch cost ~6 ms; a 2560x1440x32 maximize/restore dropped from 2.3 s to 0.045 s and pointer moves need no bank switches. Two-page presentation now also works for the explicit 800x600/1024x768 profiles (no more half-drawn "scanning" frames), the hidden page is caught up while idle, and the pointer is composed in memory in one pass. Also fixed: blank VGASETUP previews, preview/saved-mode mismatch, SAFE mode cleared by a cancelled preview, midnight-flag loss, Setup's retained erase acknowledgement after "Try again", ghost pointer and dead Tab stops, Alt+Tab/Shift+Tab/numpad/menu/mouse-init defects, and a redundant console mode switch after desktop-launched programs. See `docs/ui-smoothness-2026-09-25.md`.
- Added the pinned, source-audited VBESVGA Windows 3.1 stack with EDID-selected resolution, 16-bit colour, VDD/grabber components, a resident auxiliary INT 10h stack, and source-rebuilt helper utilities. `VGASETUP` now reports VBE/EDID capabilities, enumerates and tests modes, persists the Windows resolution/depth profile on writable installed media, accepts the safe LCD-native `AUTO/60` refresh policy, and controls the IBM ThinkPad brightness EC/NVRAM path without touching unknown hardware. The Windows gate follows the negotiated VBE surface instead of assuming 640x480 and proves Calculator close, clean Windows exit, and a second Enhanced Mode launch.
- Rebuilt the SBEMU compatibility path with the Intel ICH AC'97 32-slot descriptor-ring fix and explicit codec reset, power-up, master/headphone/PCM unmute, and capability-gated variable-rate enable. `SBEMINIT` now rejects failed child termination instead of reporting a false READY state, while the direct AC'97 test uses the full descriptor ring. Focused gates produce non-silent waveforms for Intel ICH AC'97, real/protected Sound Blaster, Doom-vanille OPL2+SB, Wolf3D OPL2+SB, and original Doom OPL2+speaker.
- Replaced bootstrap-only `INT 19h` reboot with a cold-reset cascade shared by the shell, installer, and runtime: Intel ICH `CF9`, 8042 `RESET#`, then a null-IDT triple fault. The hardware-control gate proves that the chipset reset reaches QEMU's system-reset path under `-no-reboot`.
- Rebuilt the Live-CD installer path for real PATA hardware. The standalone FORMAT action resolves its ATA target before writing, while INSTALL obtains the physical CD controller/device and boot-image LBA from the El Torito `AH=4Bh` packet and reads the image with direct ATAPI `READ(10)` instead of alternating BIOS CD calls with raw HDD writes. After a real ThinkPad T23 exposed an optical `CHECK CONDITION` at source sector 10048, reads were reduced to one native 2048-byte block and gained twelve same-block retries, CPU-independent retry pauses, ATAPI Error/sense-key diagnostics, and periodic selected-device `DEVICE RESET` recovery without channel-wide SRST. Polled IDE operations mask unsolicited IRQs and use bounded timeouts. Installation is transactional: sector zero is invalidated and flushed first, D: is patched to C: in-flight, every payload write is flushed, and the bootable MBR is committed last. Failure never reboots a partial target. Gates now inject a one-shot optical EIO at the observed sector and require recovery plus a full byte-for-byte clone, force a 5% interruption and prove the partial disk cannot boot, and require HDD-only startup from C:.
- Removed Windows 3.1's fixed per-program DOS memory ceilings: generated `_DEFAULT.PIF` and `DOSPRMPT.PIF` profiles now request all available conventional, EMS, and XMS memory, while DOSMGR-selected synthetic PSPs receive a generic conventional arena. Windows startup records its baseline EXEC depth and every later Win16/DOS-VM frame unwinds independently, preventing cumulative memory loss after Media Player or another child closes. The focused gate now proves clean generic `COMMAND.COM` return, progressing `CANYON.MID` playback with objective AdLib waveform evidence, and an unprofiled DOS/4GW Doom launch/exit before the existing Alt+F4, Windows exit, mouse, and relaunch checks.
- Made DOS/Windows mouse ownership process-safe: normal top-level EXEC return now removes transient `INT 33h` and BIOS client state, nested EXEC preserves the suspended parent's state, and TSR termination remains resident. Once a BIOS `INT 15h/C2` client installs its PS/2 callback, IRQ12 no longer delivers the same packet to a DOS `INT 33h` callback. Windows also defensively resets transient state before WIN386 can reuse old program memory. The Windows gate deliberately exits a probe without unregistering its callback, moves the mouse before `WIN`, then requires linear single-pointer movement, task-scoped `Alt+F4`, native audio, clean exit, and relaunch in that same boot.
- Fixed the resident `INT 33h` high-rate input path: mouse packets arriving while a DOS application's FAR callback is active are now drained from the coalescing slot before IRQ12 returns, so motion and button releases cannot remain stranded in Costa or DOS Navigator. `MOUSECB.COM` now holds its first callback open across nested movement/press/release IRQs, and the compatibility gate requires the pending callback drain plus DOSNavigator exit and same-boot cleanup. The attempted global SDL warp-relative workaround was removed because its synthetic recentering events regressed DOS clients; canonical QEMU runs now force raw-relative input even if the host environment inherited the warp hint.
- Made the Windows 3.1 PS/2 pointer linear and predictable through Windows-only `MOUSE.INI` settings, leaving the shared CiukiDOS `INT 33h` path unchanged. The full build now expands and installs the original Microsoft Sound Blaster 1.5 and AdLib drivers from the user-supplied Windows media, configured for SB `A220 I7 D1` and OPL2 `388`; the focused gate requires exact 1:1 cursor displacement and an objectively non-silent native Windows WAV.
- Added a four-layer DOS audio acceptance gate covering real-mode SB16 DSP/DMA1/IRQ7, DOS/4GW protected-mode timer/DMA/IRQ reflection, external AdLib/OPL2 music, and doom-vanille's combined OPL2-music/SB16-SFX AudioLib mixer. Device/code selection, DMX return 10, healthy gameplay, and objectively non-silent/non-constant WAV output are required.
- Exposed standard AdLib/OPL2 alongside SB16 and PC speaker in every full/full-CD runner. Original Doom now defaults to OPL2 music plus stable PC-speaker SFX; doom-vanille defaults to OPL2 plus SB16 SFX. The proprietary original Doom SB16/DMX branch remains explicitly unsupported.
- Restored the complete VGA mode-03 shell contract after every external child: video mode/font, page zero, cursor shape, intensity state, title bar, and prompt are rebuilt. A hostile `VIDLEAVE.COM` probe deliberately exits from mode 13h, and the screenshot gate requires clean 720x400 text output.
- Added a measured opt-in `vga-fast` TCG JIT profile for legacy planar VGA. Doom-vanille's 350-gametic timedemo improved from 1106 KVM realtics to 172, and focused TCG workflows pass Wolf3D, Costa/cursor/Calculator, DOSNavigator/mouse/navigation/Colors/exit, and Windows 3.1 start/mouse/Alt+F4/exit/relaunch. KVM remains the default because QEMU 11.1 TCG crashes during original Doom gameplay; the safe one-instruction mode is stable but too slow.
- Fixed project-owned COM launchers that performed nested `AH=4Bh` without first releasing their unused arena. `DRVLOAD`, `PMIRQSB`, `DOOMSFX`, `DOOMVAN`, `DOOMSB`, and `NETCFG` now relocate their stack and shrink through standard DOS `AH=4Ah`; `DRVLOAD /AUDIO` again launches `SB16INIT.COM`, observes DSP/DMA/IRQ completion, and returns cleanly.

The general build now rebuilds the local source automatically, and the gameplay gate rejects title screens and striped wall columns.

## pre-Alpha v0.7.1 (2026-09-01)

Status alignment (2026-09-01): Phase 5 is **CLOSED** on the canonical `full`/`full-cd` ownership boundary. Stage1 is a 1,542-byte loader-only component at `0x0800`; stage0 reads 8 sectors while the BPB/disk slot remains 72 sectors (36,864 bytes). The wholesale `CIUKIDOS.SYS` DOS kernel is resident at `0x0900`, exports `ABI=2` with 11 services, 8-byte descriptors and capability mask `0x003F`, and reports `CHAIN=0` because no legacy Stage1 DOS far-chain remains. Its current artifact is 43,254 bytes with a hard maximum of `0xA900` (43,264 bytes); the four EXEC-state frames occupy `0x1400-0x1457`, and Stage2 starts at `0x1480`. Phase 6 remains active because its quantitative external corpus and full JFT/SFT behavioral depth are incomplete. Phase 7 has controlled audio groundwork but is not closed. Phase 8 has its first bounded networking milestone complete. Phase 9 is active with a bounded Windows 3.1 Enhanced Mode workflow complete, but broader Windows 3.1 and Windows 95/98 remain open.
