## `ciuki/abi.h`

Source: `src/kernel/include/ciuki/abi.h`.

CiukiOS native ABI v1; authority: docs/design/execution-abi.md (F2),
docs/design/posix-subset.md. Wire addresses are uint32_t, never C pointers.
Research (2026-10-10):
https://raw.githubusercontent.com/torvalds/linux/v6.12/include/uapi/asm-generic/errno-base.h
https://raw.githubusercontent.com/torvalds/linux/v6.12/include/uapi/asm-generic/errno.h
https://raw.githubusercontent.com/coreboot/seabios/rel-1.16.3/src/kbd.c
https://gcc.gnu.org/onlinedocs/gcc/Structure-Layout-Pragmas.html
Decision: scoped pack(4) preserves the contracted i386 alignment even in
host checks; no packed(1), host POSIX types or host pointer widths.
SPDX-License-Identifier: MIT
This public ABI header is MIT-licensed so that programs of any licence can
include it and link the SDK runtime; the kernel itself stays GPL-2.0-only.

```c
#define CIUKI_MASTER_VALUE "Master"
#define CIUKI_MASTER_DEFAULT 20u
static inline int32_t ciuki_master_pack(unsigned l, unsigned r, unsigned mute)
{ return (int32_t)(l | (r << 8) | (mute << 16)); }
static inline int ciuki_master_unpack(int32_t v, unsigned *l, unsigned *r, unsigned *mute)
{
    if ((uint32_t)v & ~0x1ffffu) return 0;
    unsigned left = (unsigned)v & 255u, right = ((unsigned)v >> 8) & 255u;
    if (left > 100 || right > 100) return 0;
    *l = left; *r = right; *mute = ((unsigned)v >> 16) & 1u; return 1;
}
```

```c
static inline int ciuki_present_choose_mode(const struct ciuki_display_info *info,
                                            const struct ciuki_present_surface *s)
{
    if (!info || !s || !s->width || !s->height || info->mode_count>32 ||
        s->format<1 || s->format>4) return -ENODEV;
    unsigned depth=s->format==CIUKI_PRESENT_INDEX8 ? 8 :
        s->format==CIUKI_PRESENT_XRGB8888 ? 32 : 16;
    int best=-1; unsigned rank=3, area=0;
    for (unsigned i=0;i<info->mode_count;++i) {
        const struct ciuki_display_mode *m=&info->modes[i];
        if (!m->linear || (m->bpp!=16 && m->bpp!=32) || m->width<s->width ||
            m->height<s->height || m->pitch<(uint32_t)m->width*(m->bpp/8)) continue;
        unsigned r=2, a=(unsigned)m->width*m->height;
        if (m->width==s->width && m->height==s->height && m->bpp==depth) r=0;
        else if (m->width%s->width==0 && m->height%s->height==0 &&
            m->width/s->width==m->height/s->height && m->width/s->width<=3) r=1;
        if (best<0 || r<rank || (r==rank && a<area)) {best=(int)i;rank=r;area=a;}
    }
    return best<0 ? -ENODEV : best;
```

## `deskui/textarea.h`

Source: `apps/libdeskui/textarea.h`.

SPDX-License-Identifier: MIT
libdeskui multi-line text area: editing model, word wrap layout, rendering
and input handling for a Notepad-class editor (f2-32).

The buffer holds UTF-8 with "\n" line breaks. Each character occupies one
6x13 cell of the theme's monospace face (Inconsolata 12; a tab advances to
the next multiple of 8 cells, counted from the start of the visual line);
characters the face lacks (beyond Latin-1, control characters) are drawn
as a hollow placeholder box.

character boundary. Keys and text reach the widget through libdeskui's

## `deskui/v3.h`

SPDX-License-Identifier: MIT
