## Lead decisions on the contract's open points

1. **Syscall numbers.** 75–77 are taken since the contract was written (`CIUKI_SYS_LAUNCH_MARK=75`, `DEVICES=76`, `DISPLAY_ACCEL=77`; `W32=96`). The F6 calls keep the contract's order and semantics, renumbered contiguously **78–90**: `socket`=78, `bind`=79, `connect`=80, `listen`=81, `accept`=82, `sendto`=83, `recvfrom`=84, `shutdown`=85, `sockname`=86, `sockopt`=87, `poll`=88, `resolve4`=89, `netctl`=90 (`netctl` stays `ENOSYS` for the configuration directive). Amend the contract table in place with a dated note; the records, register conventions, lengths and error sets are approved as drafted; `docs/design/execution-abi*.md`/the POSIX subset document gain the approved extension.
2. **Memory.** The 4 MiB ceiling and the pool split are approved provisionally. The directive measures the real object sizes (pbuf pool entry, tcp/udp pcb, netconn, socket, mbox) in the host harness and records them in the report and in `docs/validation/`; the pool is a kernel owner (`net`) in the f0-42 memory ledger; 128 MiB admission as in the contract.
3. **Entropy** for ephemeral ports, TCP ISN and the DHCP xid: per-boot mix of TSC low bits sampled at several boot events, the RTC, the PIT phase and the primary MAC, into a SplitMix64 state; no cryptographic claim; documented in the validation note.
4. **Adapters.** T23 = Intel 8255x (`e100`, qualified driver). E500 and the 3c905 card stay with their later directive. DOS NE2000/IPX bridge: later directive. Browser: NetSurf (owner decision); its directive comes after this one. Configuration grammar and applet: later directive.
5. **Pinned archive.** `build/downloads/lwip/lwip-2.2.1.zip`, 5,087,893 bytes, SHA-256 `7b622662dba2383d71f874f2e494b54ae948531559c17acbe75797966d646878`, from `https://download.savannah.nongnu.org/releases/lwip/` (release 2.2.1, February 2025; `lwip-2.2.1.zip.sig` retained next to it, not verified: no project key). The build verifies the hash before extracting into `build/external/lwip-2.2.1`, exactly like `sdk/freetype/build.py` does for FreeType; never downloads, no fallback. Upstream files are not edited; a patch set, if needed, lives as files with the reason.

## Required

1. **Import.** `src/kernel/net/lwip/` (or a build rule that compiles the upstream tree in place): `core` (init, mem/memp, pbuf, netif, timeouts, ip4, icmp, udp, tcp*, dhcp, dns, etharp/ethernet), `api` (`tcpip`, `api_lib`, `api_msg`, `netbuf`, `err`; **not** `sockets.c`: the native ABI is the kernel's), `lwipopts.h` per the contract's "Baseline configuration", `arch/cc.h`. BSD-3 notice and the import record (version, hash, file list) under `src/kernel/net/lwip/` and `docs/licenses` as the project does for other imports. The kernel build (`scripts/build_kernel.py`, i686 `-Werror`, no SSE/x87) includes it.
2. **`sys_arch`** per the contract's "Threads and `sys_arch`": the tcpip thread, mutex/semaphore/mailbox on kernel primitives, timeouts on the kernel clock, core locking as the contract fixes it; a host build of the same `sys_arch` on the pthread shim (the `FS_HOST` pattern) runs the real stack in `tests/host`.
3. **netif on the driver boundary.** The frame path from `src/kernel/drivers/net.c`/`net_dev.c` (the `netif_driver` interface, interrupt mode, the queues and quarantine of f6-01) into lwIP's netif input/output with copied frames as the contract requires; link state to `netif_set_link_*`; the f6-01 native ARP evidence path (`net_arp.c`) is retired or kept per the contract ("Repository comparison"): decide, record, keep the f6-01 host tests green either way.
4. **Native calls 78–89** with the contract's records and semantics: fd integration with the common descriptor table (close, dup, inheritance, `O_NONBLOCK`), readiness and `poll` shared with the existing fd readiness model, interruptible waits (signals, process exit), input validation and copy bounds, loopback and numeric IPv4; `resolve4` on lwIP DNS; DHCP client on the primary interface with the lease transitions the contract describes (the UI comes later).
5. **SDK and libc.** Headers under `sdk/` (`sys/socket.h`, `netinet/in.h`, `arpa/inet.h`, `netdb.h`, `poll.h` subset) with the frozen layouts; newlib-port wrappers for the calls; `getaddrinfo`/`freeaddrinfo`/`gai_strerror` over `resolve4`; `inet_aton`/`inet_ntoa`/`htons` family; ABI layout expectations for every new record in `tests/host/abi_layout_test.c` and the dump.
6. **Tests (T0).** Real-stack host harness: loopback TCP and UDP through the native call layer, `poll` readiness, DNS against a scripted resolver on the host netif shim, DHCP exchange against a scripted server, error sets, bounds and refusal cases; `sys_arch` unit tests; ABI tests; kernel compile check with the production flags; `make CAP= apps` once for the SDK. No QEMU: the lead runs T1–T3 with QEMU user networking (`-netdev user`, e1000/rtl8139/ne2k_pci) and the T23 afterwards.
7. **Report** `build/codex/f6-10-report.md`: verification table, measurements of decision 2, and the row-by-row status against the contract's gate "f6-02: stack and sockets".
