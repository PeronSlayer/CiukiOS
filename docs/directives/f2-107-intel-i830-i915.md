## Required

1. **Driver.** Port the chosen donor into `src/kernel/drivers/video/<id>/`, registered through the part A registry with the PCI match table of the contract section.
   - Keep the donor's origin and licence header in every imported file.
   - The driver provides FILL, COPY and SYNC.
   - Optional commands and the hardware cursor follow when the donor supports them; until f2-101d merges, implement them behind the part A hook signatures and capability bits.
   - Mode setting stays VBE unless the contract section names a native mode provider.
2. **Safety.** Probe without engine commands, verify ownership of the active frame buffer, use bounded waits, and never let the engine hold the bus.
   - A fault quarantines the driver, and the software engine takes over after the idle proof of Amendment 1.
   - The DM9 hardware check proves native execution against the software engine.
3. **Tests.** Host fake-register tests cover the register sequences of every command (fill, copy in both overlap directions, sync and timeout, cursor), the probe and refusal paths, and quarantine. Add golden comparisons against the software engine where the model allows. **First, write the ring/GTT reservation contract** (lead decision 2): the ring buffer placement in stolen memory, GTT entries owned or reserved, the firmware-programmed state left untouched, and the UMA safety. The lead reviews it from the report; then implement the 2D blitter commands.
4. **Records.** Device Manager shows the driver's display name, and the Control Panel shows it as the 2D driver. Add a row to the contract's family table with the result.

Rules (Codex): no QEMU, no systemd-run, no image build, no git mutations, no dev_diary edits, nothing deleted outside the worktree, `date` before timestamps, English, primary sources cited (datasheets, register references, donor files with path and tag). ## Amendment 1 (lead, 2026-10-23 01:14): gen2 idle and stop evidence

The i830, i845G, i855GM and i865G (gen2) are the most common integrated graphics of 2002–2004, so the gate should close with evidence rather than stay shut.
1. **Research** the gen2 completion, idle and stop protocol in:
   - xf86-video-intel's i830 acceleration (`i830_accel.c`/`I830WaitLpRing`, `I830Sync`, and the MI_FLUSH and INSTDONE usage);
   - the Linux i915 gen2 paths (`intel_ring` idle, `i8xx` IRQ and breadcrumb handling) at a pinned tag;
   - any Intel 82830/845/855/865 programmer's reference available.

   Cite exact files, lines and tags.
2. **Implement** the gen2 breadcrumb (store to the hardware status page, or the generation's equivalent that the sources prove) and a bounded stop (flush, HEAD equal to TAIL, the INSTDONE/idle bits per chip), with the same quarantine and pinned-page rules as gen3.
3. **Enable** gen2 per chip only where a cited protocol exists; a chip without one stays gated, with the reason in Device Manager.
4. **Tests:** gen2 ring, GTT and breadcrumb models, a stop timeout, and a per-chip gate table.
