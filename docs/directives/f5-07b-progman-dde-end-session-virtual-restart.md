## Required

1. **PROGMAN DDE.** `w32srv` registers the `PROGMAN` service with the `PROGMAN` topic (and `Shell`/`AppProperties` as Windows 98 did), answers `WM_DDE_INITIATE` from any Win32 process, accepts `WM_DDE_EXECUTE` command strings `[CreateGroup(name[,path])]`, `[AddItem(cmdline[,name[,icon[,index[,x,y[,workdir[,hotkey[,minimize]]]]]]])]`, `[DeleteItem(name)]`, `[DeleteGroup(name)]`, `[ShowGroup(name,cmd)]`, `[ReplaceItem(name)]`, `[Reload(name)]`, `[ExitProgman(bool)]` (no-op) with the exact Windows parsing rules (quoting, commas, multiple commands per execute), creates/removes folders and `.lnk` files under `C:\WINDOWS\Start Menu\Programs\<group>` through f5-15A's writer, answers `WM_DDE_ACK` with the documented status bits, `WM_DDE_REQUEST` for the `Groups` item (the group list in the Windows format) and the group items, `WM_DDE_TERMINATE` handling, timeouts for dead clients; DDEML subset (`DdeInitialize`, `DdeUninitialize`, `DdeConnect`, `DdeDisconnect`, `DdeClientTransaction` `XTYP_EXECUTE`/`XTYP_REQUEST`, `DdeCreateStringHandle`, `DdeFreeStringHandle`, `DdeCreateDataHandle`, `DdeGetData`, `DdeFreeDataHandle`, `DdeGetLastError`, `DdeAccessData`/`DdeUnaccessData`) if not already present.
2. **End session.** `ExitWindowsEx(EWX_LOGOFF|EWX_REBOOT|EWX_SHUTDOWN|EWX_POWEROFF[, EWX_FORCE])` → `w32srv` end-session coordinator: the desktop prompt of the contract for reboot/logoff ("Setup wants to restart Windows. CiukiOS will close all Windows programs and finish the installation."), `WM_QUERYENDSESSION` (with `ENDSESSION_LOGOFF` where applicable) to every top-level window of every Win32 process in z-order, a refusal cancels (unless `EWX_FORCE`), `WM_ENDSESSION`, termination after 10 s of any process still running (recorded `[win32] exit reason=restart`), hive commit, then the restart or the plain end; `EWX_SHUTDOWN`/`EWX_POWEROFF` end only Win32 programs and tell the desktop (no power action by the personality); `AbortSystemShutdown`/`InitiateSystemShutdown` of `advapi32` map to the same coordinator with Windows 98 answers.
3. **Virtual restart.** After the processes end: `w32srv` processes `C:\WINDOWS\WININIT.INI` `[rename]` (destination=source pairs, `NUL` destination = delete, short and long names, the ordering and overwrite rules of Windows 9x, bounded by file count and size, errors recorded and the line skipped), renames the file to `WININIT.BAK`, runs `HKLM\...\RunServicesOnce` then `HKLM\...\RunOnce` then `HKCU\...\RunOnce` entries once in registry order with `CreateProcess` and waits for each (bounded by a 5 min watchdog per entry, recorded), deletes each entry before running it (as Windows did), then `Run`/`RunServices` entries are NOT run (no session concept beyond the desktop's), resumes the desktop and shows the Start menu refresh; the restart is idempotent if interrupted (a journal under `C:\WINDOWS\CIUKIRST.LOG`), `w32srv` itself restarts without losing committed keys (f5-07A), the desktop's input is restored within 2 s of the last process exit.
4. **Evidence.** DDE transcripts for every command with malformed inputs (authored fixtures, both raw-message and DDEML clients), end-session traces (accept, refuse, force, 10 s termination), `WININIT.INI` fixtures (copy, delete, rename chains, missing sources, read-only targets, short names), `RunOnce` ordering and deletion, interrupted restart replay, hive commit before restart, all on the Linux adapter with f5-09's desktop harness for the dialogs; `make CAP= apps`, `python3 -B -m unittest discover -s tests/host/win32 -t .`, `python3 -B -m unittest discover -s tests/host/desktop -t .`.
