2. **Memory, processes, threads.** `VirtualAlloc`/`VirtualFree`/`VirtualProtect`/`VirtualQuery` on the f5-03 virtual-memory service, `HeapCreate`/`HeapAlloc`… on ntdll heaps, `CreateFileMapping`/`MapViewOfFile` on f5-04 sections, `GlobalAlloc`/`LocalAlloc` families, `CreateProcess` with the contract's search rules and environment/command-line inheritance, `CreateThread`/`ExitThread`/`TerminateThread`, waits (`WaitForSingleObject`, `WaitForMultipleObjects`, `MsgWaitForMultipleObjects` deferred to f5-10's queue), fibers, TLS, `Sleep`, critical sections re-exported, `GetTickCount`/`QueryPerformanceCounter` on the PIT counter, `GetSystemTime`/`GetLocalTime`/time zone (one zone, the contract's), `GetVersion`/`GetVersionEx` (Windows 98 identity per the contract), `GetSystemInfo`, `GlobalMemoryStatus`, environment and command line, code pages 437/850/1252 and `MultiByteToWideChar`/`WideCharToMultiByte` for them, `GetPrivateProfileString`-family with Windows 98 INI parity (the contract's cases), Toolhelp32 snapshots, console minimum (handles to a per-process log file, `WriteConsole`/`AllocConsole` semantics as bounded by the contract), `OutputDebugString` → protected record.
