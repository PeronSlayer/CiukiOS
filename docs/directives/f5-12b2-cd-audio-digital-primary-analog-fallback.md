## Required

1. **Capability and TOC.** Per drive: MODE SENSE(10) page 2Ah bits (Audio Play, CD-DA Commands Supported, CD-DA Stream is Accurate), the TOC with Q CONTROL data-track bits, the audio-only flag in the optical state; `atapi_ready` accepts an audio first track for the media node and never for mounting; no file system probe on an audio-only disc; AutoPlay offers the CD player as Windows 98 does.
2. **Digital path (primary).** `MEDIA_CD_READ_AUDIO` over READ CD (0xBE, expected sector type CD-DA, user data 2,352 bytes, up to 27 sectors per packet as the drive allows), a reader thread per playing device feeding the f5-12A mixer at 44.1 kHz with a bounded reservoir (state the depth and the underrun policy), ranges touching a data track refused before any packet (`EINVAL`; `MCIERR_OUTOFRANGE` at MCI), position reporting from the stream, not from the drive.
3. **Analog path (explicit fallback).** PLAY AUDIO MSF, PAUSE/RESUME, READ SUB-CHANNEL for position, selected per drive when the digital read fails or the drive reports no CD-DA support; the Windows 98 CD player's "digital playback" option is the model: the selection is recorded in the launch record and may be forced per drive for testing.
4. **`cdaudio` MCI device.** The census set: open/close, status (mode, position, length, number of tracks, media present, start position, time format TMSF/MSF/milliseconds), play/stop/pause/resume/seek (to start/end/track), set time format, set door open/closed (door closed through START STOP UNIT; door open refused while playing as Windows 98 does), info, notifications; Windows 98 error codes.
5. **Fixtures and tests.** CUE/BIN fixture format with synthetic tracks (data + audio, audio-only, pregap variants), a mock transport that answers the packet set and injects errors (MEDIUM NOT PRESENT 2/3A/00, ILLEGAL REQUEST, read errors, a drive without CD-DA support), host tests for both paths and every MCI command, the error-code mapping table; the `w32-media-qemu-t23` CD-audio predicates on a QEMU `-cdrom` fixture image (the runner's optical fixture path from f4-media); host CPU cost of the digital path measured and compared with the amendment's estimate (0.18 % per second of audio).
6. **Evidence.** `scripts/test/host_kernel_tests.sh`, `tests/host/audio/run.sh`, `make CAP= apps`, `python3 -B -m unittest discover -s tests/host/win32 -t .`, the f4-media host tests.
