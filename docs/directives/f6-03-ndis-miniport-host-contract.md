# f6-03 — Hosting the Windows NIC drivers of the owner's driver pack: NDIS miniport host, contract and census

- **Model/effort:** `gpt-6.1-sol`, `xhigh`, `--search`. **Worktree:** `../CiukiOS-wt-f6-03` from `main`. Research, census tool and contract only: **no kernel code** in this directive. Owner directive 2026-10-13: the driver pack in `third_party/Ultimate Windows Driver Pack (for vista,xp,98,95,me,2000,2003)/` (1.6 GiB, 909 `.inf`, 844 `.sys`, 14 `.vxd`, git-ignored, never committed) must be integrated so that CiukiOS "starts with a large driver park". f2-43 already turned its INF files into the hardware-id database (`assets/hwids/`, 1155 PCI ids). This step decides how far the binaries themselves can be used.

## Task

1. **Census tool** `scripts/pe_import_census.py` (host-only, read-only on the pack, path by argument): for every `.sys` (and `.vxd` counted separately) read the PE headers, classify by the INF that references it (class `Net`, `Media`, `Display`, `HDC`, `USB`, …, target OS from the INF `[Manufacturer]` decorations `NTx86`, `NT.5.1`, `Win9x`), and list its imports per DLL (`NDIS.SYS`, `NTOSKRNL.EXE`, `HAL.DLL`, `USBD.SYS`, `portcls.sys`, …). Output: a JSON summary in `build/` plus tables in the report: how many drivers per class and OS, the ranked union of imported functions for the `Net` class on NT 5.x (which subset of NDIS 5.0/5.1 and of ntoskrnl/HAL covers 50 %, 80 %, 95 % of the NIC drivers), and the NICs of the 1998–2004 baseline (`docs/design/hardware-baseline.md`) they cover (3Com 3C90x, Realtek 8139/8169, Intel PRO/100 and PRO/1000, VIA Rhine, SiS 900, Broadcom 440x, DEC/Intel 21x4x, AMD PCnet, NatSemi DP8381x, Davicom).
2. **Research**: NDIS 5.1 miniport model (Microsoft DDK documentation: `NdisMRegisterMiniport`, `MiniportInitialize`, `NdisMSetAttributesEx`, shared memory and map registers, `NdisMRegisterInterrupt`, `MiniportHandleInterrupt`, send/receive packets, OIDs the host must answer); the ntoskrnl/HAL semantics those imports need (IRQL, DPCs, spin locks, `KeStallExecutionProcessor`, memory pools, registry queries for the driver's parameters, `IoConnectInterrupt`); the architecture of the Linux `ndiswrapper` project as the scope reference (both projects are GPLv2, see `LICENSE`, so reuse is licence-compatible; the project rule stays: implement from the specifications, use ndiswrapper for scope and pitfalls, and mark any copied fragment with its origin and licence); how the kernel-mode PE loader can share the parser and relocation code with the F5 user-mode loader (`docs/design/win32-personality-contract.md`, "PE loader").
3. **Contract** `docs/design/ndis-miniport-host-contract.md`: scope (NT 5.x NDIS miniports for NICs only; Win9x VxD/NDIS3 drivers, WDM audio `portcls` drivers and display drivers excluded, each with the technical reason), the kernel-side host (`ndis.sys` and `ntoskrnl` shim implemented natively, the driver `.sys` loaded from `/System/drivers/<inf-dir>/` with its INF-derived parameters, binding to the F6 network stack as a `netif` driver beside `e100`/`ne2000`/`rtl8139`), isolation and failure rules (quarantine like the native drivers, no driver may hold the bus on fault), the IRQL/DPC mapping onto the Ciuki work and IRQ model, DMA through the kernel's physical allocator, the install flow (Device Manager "Install driver from pack" picking by hardware id, the pack stays on the owner's disk or a CD: redistribution rights are per vendor and are not assumed), the acceptance set (QEMU `e1000`, `rtl8139`, `pcnet` with their XP drivers from the pack; the T23's e100 as the hardware check against the native driver), and the directive plan after the contract (f6-04 PE kernel loader shared with f5-05, f6-05 ntoskrnl/HAL shim, f6-06 ndis.sys host, f6-07 Device Manager install flow).
4. Report the honest expectation: how many NICs of the baseline the host would add beyond the three native drivers, and the estimated size of the shim from the census.

## Acceptance

Census script with host tests on synthetic PE/INF fixtures (the pack itself is not a test input); contract document complete; no change under `src/`.
