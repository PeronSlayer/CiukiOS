# fx-exeicons: programs, shortcuts and media show their own icons automatically

- **Written:** 2026-10-27 16:05 by the lead. Implementer: Claude agent. Base: main (after 581d2ebd6).
- **Owner request 2026-10-27:** executables and similar files that carry their own icon (or an icon file meant for them) must get it automatically, everywhere CiukiOS shows them.

## Windows 98 behaviour to reproduce (research and cite it: Microsoft documentation of ExtractIcon/ExtractIconEx, SHGetFileInfo, IShellLink::GetIconLocation, desktop.ini and AUTORUN.INF ICON=, the PE/NE icon resource formats RT_ICON/RT_GROUP_ICON; Wine's shell32 implementation for edge cases)

- A PE (Win32) or NE (Win16) executable or DLL shows the first icon group of its resources; `.ico` files show themselves; `.cur`/`.ani` show their first image.
- A shortcut (`.lnk`, and CiukiOS's own desktop link format) shows its `IconLocation` (file plus index, including negative resource IDs) or, without one, its target's icon; a `.pif` shows its program's icon or the MS-DOS default.
- A folder with `desktop.ini` `[.ShellClassInfo] IconFile/IconIndex` (or `IconResource`) shows that icon; a CD or removable drive with `AUTORUN.INF` `ICON=` shows that icon on its drive.
- DOS `.exe`/`.com`/`.bat` keep the MS-DOS program icon unless a `.pif` or shortcut names another one.
- Program entries the system creates (Start menu, Games, Add/Remove Programs, installer-created shortcuts such as Quake III's and Half-Life's) use the installed program's own icon.

## Scope

1. Inventory where CiukiOS draws a file or program icon (desktop, Files views, Start menu, Games, taskbar buttons, Alt+Tab, Add/Remove Programs, AutoPlay, Run dialog history, properties sheets, Win32 `ExtractIcon*`/`SHGetFileInfo`/`LoadIcon` and window class icons) and what each uses today.
2. One bounded icon extraction service (PE and NE resource walk, ICO/CUR/ANI decode, size selection for 16/32/48 with the best available colour depth, alpha and AND-mask handling), shared by the native shell and the Win32 shell32 facade, with a cache keyed by path, size and modification time so Files stays fast. Hostile or broken resources fall back to the type's default icon, never crash or stall the desktop.
3. Use it in every place of the inventory; Win32 windows without a class icon show their executable's icon in the taskbar and title bar, as Windows 98 does.
4. Tests: synthetic PE/NE/ICO/LNK/PIF/desktop.ini/AUTORUN.INF fixtures generated by the tests (no commercial files committed), malformed-resource cases, cache invalidation, and the existing desktop, Files, shell and Win32 suites green.
