## Required

1. **Hives.** `SYSTEM.CRG` (HKLM incl. `Software\Classes`) and `USER.CRG` (HKU\.DEFAULT = HKCU) in `C:\WINDOWS\`, two slots each with version, sequence and CRC-32 over a UTF-8 text body (one key path per section, typed values), commit = write inactive slot, `fsync`, switch sequence; torn/invalid slot falls back with a `[win32] registry` record; commits at most every 2 s while dirty, on `RegFlushKey`, on writer exit, before restart/shutdown; limits per the contract (key/value names 255, data 64 KiB, 4 MiB text per hive); the default keys and the synthesised `HKEY_CURRENT_CONFIG`/`HKEY_DYN_DATA`; value types round-trip exactly.
2. **Service.** `w32srv` registered as a service endpoint (f5-04), restartable: a killed `w32srv` restarts without losing committed keys; atoms (global/local as the contract assigns), the window directory and handle allocation service for f5-10 (interfaces defined now, used later), the `GetUserName`/trivial security answers.
3. **Facades.** `advapi32` registry API with Windows 98 error codes (`RegOpenKeyEx`… `RegDeleteKey` recursive), `version` (`GetFileVersionInfo`, `VerQueryValue`, `VerFindFile`) and `lz32` (expand of `KWAJ`/`SZDD` compressed installer files) — Wine PE builds if f5-14A's audit cleared them, otherwise CiukiOS implementations; the census coverage for these DLLs = 100 % implemented or W21 stub.
4. **Evidence.** Torn-write recovery (cut at every byte position class), restart without loss, error codes for every documented failure, round-trip of all value types at the limits, concurrent writers from two processes; `ASAN_OPTIONS=detect_leaks=0 bash scripts/test/host_kernel_tests.sh`, `make CAP= apps`, `python3 scripts/gen_api_reference.py` if a public header changed. Report `build/codex/f5-07a-report.md`.
