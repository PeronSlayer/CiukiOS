# f0-47 — memory objects: virtual areas with object backing and page descriptors, demand-zero and copy-on-write faults, shared zero page, fault-safe user copies; mapped-file integration prepared with the C5 identity (contract M2)

- **Phase:** F0 (memory). **Model:** gpt-6.1-sol / xhigh. **Worktree:** `wt/f0-47` from main (after the f1-84 merge).
- **Contract:** `docs/design/win98-class-resource-management.md`, section **M2** (objects, faults, demand-zero and COW) with M1 (ledger, pins: f0-43), R1 (bounded walks: f0-44) and C5 (mapping identity table: f1-84) as constraints; audit rows M02, M06, D04; source register P21 (King), P26 (Mitchell), P24 (IA-32 SDM paging), the Windows 95 DDK VMM memory-manager topics (P02 and the f0-42b resolved rows if they cover page replacement/commitment).
- **Authority:** `src/kernel/core/vmm.c`, `src/kernel/core/pmm.c` (page descriptor array), `src/kernel/proc/uaddr.c` (`ua_extent`, `ua_mmap`, protection, fault handling), `src/kernel/arch/trap.c` (page-fault dispatch only), `src/kernel/core/ledger.c` (commit categories), `src/kernel/include/ciuki/mm.h`, `src/kernel/proc/win32/` only for the Win32 reserve/commit mapping onto the new objects (f5-04 merged before you start: coordinate on the section objects), `tests/host/` (pmm/vmm/uaddr/proc harnesses), `docs/design/boot-memory.md` (memory objects section), `docs/design/execution-abi.md` if a fault-semantics statement changes (none expected for the native ABI).
- **Not yours:** replacement and trimming (f0-48), the backing file (f0-49), DOS VM pool semantics (f3-46), the FS identity table itself (f1-84).

## Required

1. **Objects and descriptors.** Extend `aspace`/`ua_extent` with virtual-area → object backing (anonymous private, anonymous shared, zero, file-backed placeholder keyed by the C5 identity, device/MMIO as today), page index, permissions, commitment, resident-set links and generation; a page descriptor per PFN with refcount, accessed/dirty epoch, pin count (f0-43 tokens), backing kind/slot, I/O-in-flight flag and waiters. A non-present PTE never decides by itself whether an address is demand-zero, swapped (reserved for f0-49), mapped, PROT_NONE, guard or invalid: the object does. Shared surfaces, Win32 reserves and the existing protection/fault signal semantics stay distinct and unchanged for native programs.
2. **Faults.** Commit reserves backing capacity in the ledger (RAM commit now; pagefile commit = 0 until f0-49); demand-zero materialises a cleared page only when touched; a shared read-only zero page with a private zeroed page on write; private sharing with PFN references and write faults (COW), reserving the possible COW write commitment before promising it; permission, guard, kernel and invalid-address faults stay faults; no frame is ever exposed before zeroing or a verified page-in; faults on one page coalesce into one operation with a generation check after every sleep.
3. **User copies.** `copy_user` helpers pin or fault in pageable ranges *before* entering locks their pager could need (R1 rule); the raw copy assembly stays, the preparation step is new; assert the lock order in host tests.
4. **Host evidence.** Untouched committed regions allocate no data PFNs; first read is zero; write allocates once; two private aliases diverge; shared aliases stay coherent; protection faults remain faults; failure injected at every allocation and page-table stage; unmap/exit raced with faults; free and commit counts return to baseline after 100 lifecycle cycles (ledger reconciliation); every new walk passes the R1 bound tests of f0-44 (`as_destroy`, `ua` walks). `ASAN_OPTIONS=detect_leaks=0 bash scripts/test/host_kernel_tests.sh`, `python3 scripts/build_kernel.py`, `python3 scripts/gen_api_reference.py` and `make CAP= apps` if a public header changed (the native ABI must not change). Report `build/codex/f0-47-report.md`: the object model, descriptor memory cost per MiB of RAM on 128/256/512 MiB, fault paths, tests, remaining.

## Constraints

Use `rg` and `sed`, never `semble`. No QEMU, no `systemd-run`, no image builds, no commits, no diary edits, host tests one at a time with `nice -n 19`. No cap or admission change (M1), no paging to disk (f0-49), no new `panic()` paths except genuine invariant violations already covered by policy; no production-behaviour change under `#ifndef NDEBUG`.
