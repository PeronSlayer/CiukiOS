## Required

1. **Sizing.** Total-cache floor 2 MiB, initial allocation up to 8 MiB (today's fixed size), ceiling `min(32 MiB, U/8)` with U the usable NORMAL RAM from the ledger; metadata, workspaces, writeback buffer, mappings and pinned fills count against the budget; the memory-pressure reserve (M1 low/high watermarks) takes precedence over growth. `cache_init` keeps its contract for the fixed part; growth adds descriptor/data pages in units the layout supports (f4-04 page layouts), shrink releases them; the ledger shows the cache categories moving.
2. **Feedback windows.** 100 ms windows: grow at most 256 KiB per window after two windows of useful misses with free NORMAL above the high watermark; suppress growth under pressure, poor prefetch usefulness or dirty debt above the C1 budget; reclaim unpinned clean pages first, up to 256 KiB per ≤ 1 ms CPU slice, down to the floor; eligible dirty pages are queued for writeback (never flushed synchronously in an allocator, never while holding a PMM lock); pinned and error pages make the unreclaimable fraction explicit; shared mapped frames counted once (C5 identity table of f1-84).
3. **Per-stream read-ahead.** Per open description: last offset, sequential-run count, prefetch window, generation, useful/wasted bytes, outstanding requests; after two adjacent reads prefetch 16 KiB, growing on use to at most 64 KiB per stream; cancel/decay on seek, close, pressure or competing demand; total speculative resident bytes ≤ C/8; speculative reads use the lowest request priority (f1-83); never read across EOF or a media generation; the bounded FAT metadata read-ahead and dirty-cache hits stay; no second private data cache. If f0-42b fixed `ReadAheadThreshold` units and default, implement the compatibility setting with those semantics (documented), otherwise CiukiOS's byte-unit knobs only.
4. **Host evidence.** Traces showing growth under useful repeated reads, shrink under anonymous-memory pressure (ledger model), zero reclaimed pinned or dirty pages, bounded CPU per slice; sequential prefetch reducing device commands by a reported factor; randomized 16 KiB reads not delayed by prefetch and waste within the cap; steady-state CPU and RAM at 128/256/512 MiB profiles (host models). `ASAN_OPTIONS=detect_leaks=0 bash scripts/test/host_fs_tests.sh`, `ASAN_OPTIONS=detect_leaks=0 bash scripts/test/host_kernel_tests.sh`, `python3 scripts/build_kernel.py`. Report `build/codex/f1-85-report.md` with the sizing arithmetic per profile, the window policy, the trace tables and remaining.
