## Required

1. **Research reconciliation (M1).** Read the linked MS-DOS, RBIL, DDK and FreeDOS sources in f3-48 before implementation; recover the missing DDK hook/reflection/SFT topics if available and state their access status. Record exact versions/functions for behavior taken from FreeDOS; copy no FreeDOS kernel implementation. Resolve any mismatch between the table's proposed error class/action mapping and documented/reference behavior before freezing expected outputs. A host model's existing bugs are not an oracle.
2. **Owned state and dispatch (M1).** Implement `dos_file_dispatch` returning CHAIN/DONE/PENDING and a completion/cancel path. Own per-VM SFT and per-PSP JFT/DTA/error associations, shared DOS CDS/default drive, DOS4+ guest SFT mirror, and lifecycle entrypoints described by f3-50. Perform checked guest-memory access before side effects. Admit real resources before truncating/creating. Respect FF free slots, expanded JFT pointers and the 232-entry personality ceiling; do not promise more descriptions than admitted VFS capacity. Mirror after changes and refuse forged indices. Preserve 34h/5D06h/52h visibility.
3. **Routing and trace (M2).** Take every DF1 VMM function before CiukiDOS, including DOS/4GW translated and DJGPP/DPMI real-mode calls. Unknown calls chain once in the same V86 frame to the saved next vector. Retain host-issued 48h–4Ah/62h, vector hooks and 4B/4C/4D semantics. Instrument entry **and actual return**, not just vector dispatch time. Trace format: `group=dos_api vm=… gen=… seq=… phase=enter|return psp=… origin=… vector=21|2f ax=… bx=… cx=… dx=… ds=… es=… si=… di=… cf=… bytes=… monitor_us=… wall_us=… dropped=…`. Hex register widths are four digits; sequence/generation prevent ambiguous pairing. Include chained calls via a bounded return observer that does not single-step whole games or interfere with f3-45's ISR return tracking. No production compile-time test variants; trace is selected at runtime. Bounded RAM storage reports drops and drains after the workload; UART printing cannot be charged as file service latency.
4. **Private image and native views (M2).** Mount the logical private FAT16 volume once through native FAT and the f3-47 provider, with per-VM VFS for private C. Global native volumes keep their existing global VFS node registry; a drive view translates letters without remounting them privately. Reuse f3-47's block LRU/overlay/generation and its accounting; no new data cache, windows or copied images. Add a provider seam to native FAT/cache access if necessary, not a second FAT parser in the bridge. Serialize raw/file writes and invalidate mapped clusters/metadata on overlap. Cold mapping may read sectors; subsequent file reads must generate no guest INT13. Compact-base zero tail and overlay writes remain coherent. Map native system to read-only D and stick to E subject to existing policy; reject raw access to native mounted volumes.
5. **Core handles and namespace (M3).** Implement 3C–43,45–47,4E/4F,56,5700/01,60,67,68, plus 0D/0E/19/1B/1C/36 and regular-file IOCTL/drive queries in DF1. Handle NUL/CON/standard-handle redirection without guessing type from handle number. Positions are shared for dup/inheritance; separate opens stay independent. 40/CX=0 resizes at position, EOF is a successful short read, partial writes report exact count, seek preserves DOS signed displacement and failure behavior. Rename is atomic with its sharing preflight and cross-volume failure 17. Dates are stored metadata. Find uses exact 43-byte DTA with guarded, copyable, generation-checked cursor and correct attribute/wildcard semantics. Reuse persistent FAT aliases; build the specified deterministic aliases only for sources lacking them. Support concurrent native operations through the common claims.
6. **SHARE/locks/extended open (M4).** Implement every DOS2–6.22 compatibility-matrix cell, same/different PSP and read-only exception, explicit bidirectional deny checks, inheritance bit and native-client conflicts. Add common per-node range locks with PSP/description ownership, duplicate/inherited close behavior and teardown release; validate offset/length overflow, zero-length and EOF-spanning ranges against reference. Implement 5A unique creation with checked writable tail, 5B exclusive creation, 5C00/01, 6C00 action combinations/status/attributes and BH no-critical/auto-commit flags. No check-then-create race and no successful lock stub. Advertise SHARE via 2F/1000 only when the bridge supplies it; do not claim a network redirector at 1100.
7. **Errors/deadlines/INT24 (M5).** Implement the DF5 mapping and persistent 59h context for every failure source, including callback and cleanup failures. Publish extended error before calling INT24. Suspend without storage locks, construct the documented frame, allow 59h/console nesting only, and implement Retry/Abort/Fail plus permitted Ignore. Retry revalidates media and cannot extend the total 2000 ms request deadline. Abort follows DOS termination and affects only that process/VM as appropriate. Expired/removing media invalidates descriptions/cursors by generation. Add cancellable VFS admission/transport and cancellation-safe ticket advancement if absent. Checkpoints outside a synchronous blocking call do not meet this requirement. `vfs_wait` preserves drive/owner/reason/elapsed plus timeout/cancel outcome. Stop during a callback or I/O cannot leave stale guest writes, held locks, worker wait or references.
8. **Host closure (M6).** Supply the following meaningful tests, run sequentially with `nice -n 19`, using production bridge/VFS code and explicit fake time/media/guest memory. Extend `host_kernel_tests.sh` to compile/run the standalone bridge harness; the harness also has a documented focused command. Do not introduce a Python filesystem emulator as a passing substitute.
