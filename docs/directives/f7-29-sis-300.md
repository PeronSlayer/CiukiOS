## Family constraints
- Submission: MMIO register writes and the MMIO vertex registers (`SIS_MMIO_WRITE_VERTEX`), with the command-queue length check before every write group; no AGP command queue (`AGPCmBase`/`AGPTtDwNum` stay research notes).
- Depth: D16 first (Z format in `ZSet`); D24/D32 only if the fake engine and the probe cover them.
- Two texture units with 1024 maximum size and per-level pitch registers (`TexturePitch0..10`): the layout facet must model the level pitches and the texture cache flush (`TEnable` texture-cache bit toggling in `sis_context.c:605-608`).
- The 300 generation's integrated variants (540, 630) share system memory as VRAM: the heap plan must use the 2D driver's measured VRAM and reservations, never a fixed size.

## Acceptance criteria
- Host fake-engine differential tests pass against the scalar reference for every admitted state; refused states select software for the whole context and never emit.
- Register and validator fuzzing: no write outside the whitelist or the claimed heap, no queue overflow, no unbounded wait.
- Probe containment proven on success, refusal, timeout and fault paths.
- No admission without a passed Q1–Q4 qualification in the current boot; marker `3d-sis300`; the 315 registration never nominates a backend.
- Design document cites file:line for every register.
