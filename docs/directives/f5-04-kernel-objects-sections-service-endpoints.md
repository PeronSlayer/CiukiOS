## Required (the contract is the specification; this section fixes scope and evidence)

1. **Objects and handles.** Generational handle tables per process with the inheritance bit, the object types of the contract's "Handles and kernel objects" table (process, thread, event auto/manual, mutex with abandonment, semaphore, waitable timer, file, section, file mapping view, message queue, window-station placeholder as the contract defines), reference counting with the ledger charge per object, `DuplicateHandle` semantics across processes, close-on-exit cleanup verified by 100 create/exit cycles returning every ledger counter to baseline.
2. **Waits and APCs.** `WaitForMultipleObjects` wait-all atomicity and wait-any ordering, timeouts with the shared user data page clock, alertable waits and user APC delivery order (FIFO per thread), mutex abandonment, suspension and `SetThreadContext`/`GetThreadContext` with the FXSAVE context of f5-03, the message-queue object and cross-process posting with the 10,000-message quota and the queue-full behaviour the contract states.
3. **Sections and mappings.** Image sections with shared builtin pages (copy-on-write for writable sections), pagefile-backed sections (zero-filled, committed on demand within the RAM commit of f0-43's ledger; no swap yet), file-backed sections through the VFS with coherent views (write-through to the file cache; document the coherence rule with f1-82's cache), `MapViewOfFile` offsets/alignment, `VirtualProtect` on views, and the per-process budget of the contract's table measured on the host model.
4. **Service endpoints.** Registration of `desktop` and `w32srv` as service processes with per-process endpoints (the channel model of `proc/channel.c` extended as the contract's "Personality architecture" describes), authority dispatch and charges per the contract; the priority mapping and the focus boost use f0-45's tables and input hints (no second mechanism).
5. **Host evidence.** Deterministic interleaving tests (wait-all atomicity, abandonment, APC order, queue quota, handle inheritance and duplication, section COW and coherence, 100 create/exit cycles with ledger reconciliation), the production win32 harness under ASan/UBSan, `ASAN_OPTIONS=detect_leaks=0 bash scripts/test/host_kernel_tests.sh` complete, `python3 scripts/build_kernel.py`, `python3 scripts/gen_api_reference.py` and `make CAP= apps` if a public header changed. QEMU case `w32-objects-qemu-t23` written in `tests/suites/f5-core.json`, unrun (owner decision 2026-10-19-03).
