## Required

1. **Formats and scaling.** Source RGB565, XRGB1555, 8-bit indexed with 256-entry palettes (partial palette updates), converted to the native framebuffer formats of the baseline (16/32 bpp) with integer scaling (1×, 2×, 3× with letterbox/pillarbox per the contract) and a gamma LUT; pinned conversion digests per format and scale on the host; cost per frame measured at 320×200, 640×480 and 800×600 on the host (-O2) with the i686 code audit (no SSE in the kernel presenter per the baseline).
2. **Delegated present lease.** A Win32 process holding the present lease (full-screen exclusive) presents frames through the presenter with pacing (vsync when available, otherwise the contract's timer pacing); synchronous revocation when the desktop or a DOS VM takes the lease (the f3-43 rules: ownership proof, generation, interval), with the revocation race test; mode switching on behalf of the lease holder through the desktop (the modes of the hardware baseline; rollback on failure as f0-40 defined).
3. **Windowed path.** The windowed Win32 program's surface goes through the desktop protocol v3 surfaces of f5-09 (define the shared surface format and damage rules jointly; this directive provides the conversion/scaling helpers the compositor reuses).
4. **Evidence.** Host digests and the revocation race; the T23 check of 640×480×8 and 320×200×8 at 2× is the lead's (recorded as pending); `ASAN_OPTIONS=detect_leaks=0 bash scripts/test/host_kernel_tests.sh`, `python3 scripts/build_kernel.py`, `python3 scripts/gen_api_reference.py` if a public header changed. Report `build/codex/f5-08-report.md` with the format table, costs, the lease state machine and remaining.
