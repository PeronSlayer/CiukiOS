# f6-11 — DOS LAN: virtual NE2000 per VM, Ethernet/IPX bridge to the physical port, IPX API emulation in the VMM (contract section "DOS virtual NE2000 and Ethernet/IPX bridge")

- **Owner:** Codex, `gpt-6.1-sol`, effort `xhigh`, `--search` allowed (DP8390 datasheet, the QEMU `ne2000.c` model, Novell IPX/SPX programmer's reference material in the public domain of the era, id Software's released DOOM source `IPXSETUP.C`/`IPXNET.C` as the primary reference for the API subset)
- **Written:** 2026-10-20 by the lead (owner's 1.0 Beta goal: DOS games in LAN; the owner decided 2026-10-20 that F6 runs in parallel with F5)
- **Worktree:** `../CiukiOS-wt-f6-11`, branch `wt/f6-11`
- **Contract:** `docs/design/network-contract.md`, section "DOS virtual NE2000 and Ethernet/IPX bridge" (every MUST applies) and "Security and failure containment"

## Lead decisions (the contract leaves them to the lead)

1. **IPX for the guests is emulated by the VMM**, not supplied by a Novell driver (none is redistributable): the kernel implements the DOS IPX API the era's games use — detection (`INT 2Fh AX=7A00h` returning the far entry, `INT 7Ah`), `IPXOpenSocket`/`IPXCloseSocket` (dynamic and fixed sockets), `IPXSendPacket`/`IPXListenForPacket` with ECBs and fragment descriptors in guest memory, `IPXGetInternetworkAddress`, `IPXRelinquishControl`, `IPXGetIntervalMarker`, `IPXScheduleIPXEvent`/`IPXCancelEvent`, ESR callbacks as the API defines them (guest-side upcalls executed by the VM at a safe boundary, never host code in the guest), network 0 with the VM's MAC as node, immediate address = destination node. Frames leave the VM as **Ethernet II IPX (0x8137)**, the frozen format; raw 802.3 and LLC IPX are not accepted in this directive. The API subset is exactly what `IPXSETUP.C`/`IPXNET.C` of the released DOOM source and the comparable network code of Duke Nukem 3D/Descent/Rise of the Triad call; document each call with its source reference.
2. **The virtual NE2000** of the contract is implemented too (DP8390 model, ports 0x300–0x31f, IRQ 3, 16 KiB packet RAM, remote DMA by copy only) so that a guest packet driver (the GPL Crynwr NE2000 packet driver from FreeDOS, pinned by a later directive) can drive it for guest TCP/IP; it is not on the IPX path of decision 1.
3. **Peers:** two CiukiOS machines on one switch, or one CiukiOS machine and CiukiOS in QEMU bridged on the same LAN (`-netdev tap`/bridge); the lead runs the DOOM gate; the directive's host tests prove frame-level and API-level behaviour between two emulated VMs and the physical-port tap.
4. **Conflict rule with f6-10 (lwIP, running in parallel):** new files only (`src/kernel/vm/dosvm_ne2000.c`, `src/kernel/vm/dosvm_ipx.c`, `src/kernel/net/bridge.c` and headers); `src/kernel/drivers/net.c` gains one registration hook (`net_bridge_tap_register`/`unregister`, a frame tap with type filter) in a clearly delimited block and nothing else; IPX bypasses lwIP entirely as the contract requires.

## Required

1. **Bridge** (`src/kernel/net/bridge.c`): per-VM RX/TX queues of ≤ 8 frames on the global packet pool, round-robin, 256 frames/s (burst 32); fan-out rules of the contract (broadcast to other eligible VMs and the physical port once; unicast for a local VM never on the wire); unique locally administered MACs from a persisted per-host random identifier plus VM identity with collision checks; source-MAC and destination filtering; promiscuous receive on the physical driver only while a bridge VM exists, with software filtering; drain on disable/link loss/VM destruction; at most two network-enabled VMs.
2. **Virtual NE2000** per the contract's register list, tested against the datasheet and the QEMU model (register-level host model in `tests/host/vm` like the SB16/PIT device tests).
3. **IPX API emulation** per decision 1 in `dosvm_ipx.c`: ECB lifecycle, listen queues per socket, send with fragment gathering from guest memory under the f0-44 pin rules, ESR upcalls through the existing VM callback boundary, bounded tables (sockets ≤ 32 per VM, ECBs ≤ 64 per socket), typed completion codes as the API documents; the VM's launch record gains `network=ipx` and the DOS Box settings a "Network: IPX (LAN)" option (default off; the lead decides the default later).
4. **Tests.** `tests/host/vm`: DP8390 model; IPX API harness driving two emulated VMs through the bridge (open/close, send/listen, broadcast, ESR, interval marker, cancel) with a replay of the DOOM `IPXSETUP` handshake sequence reconstructed from the source; bridge fan-out, MAC policy, rate limit and drain tests; `tests/host/fs`/`proc` untouched; kernel compile with the production flags; `make CAP= apps` once for the settings panel. No QEMU: the lead runs two QEMU instances on a host bridge and then the T23.
