## Required

1. Probe APM 1.2 through the BIOS VM (INT 15h AX=5300h) without connecting when ACPI is present and owned. When ACPI is absent, connect the 32-bit protected-mode interface with the GDT selectors the APM 1.2 specification §§4.3/4.6 defines.
2. Poll events once per second.
3. Power status covers AC, battery percentage and life, which feed the same tray and Power page as f1-110.
4. Soft-off is APM Set Power State Off after the orderly shutdown.
5. The critical suspend and low-battery policy of lead decision 3 flushes and quiesces within budget, then acknowledges. Ordinary suspend is rejected.
6. Host tests use the APM BIOS model, the ACPI-present exclusion, event handling and the shutdown ordering.
