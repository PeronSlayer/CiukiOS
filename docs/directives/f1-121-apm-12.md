## Required

1. Probe APM 1.2 through the BIOS VM (INT 15h AX=5300h) without connecting when ACPI is present and owned. When ACPI is absent, connect the 32-bit protected-mode interface with the GDT selectors the APM 1.2 specification §§4.3/4.6 defines.
2. Poll events once per second.
3. Power status covers AC, battery percentage and life, which feed the same tray and Power page as f1-110.
4. Soft-off is APM Set Power State Off after the orderly shutdown.
5. The critical suspend and low-battery policy of lead decision 3 flushes and quiesces within budget, then acknowledges. Ordinary suspend is rejected.
6. Host tests use the APM BIOS model, the ACPI-present exclusion, event handling and the shutdown ordering.

## Amendment 1 (lead, 2026-10-23 00:51): real-mode interface through the BIOS VM

1. **Interface.** Do not connect the 32-bit protected-mode interface. Ring-0 far calls into BIOS code cannot be contained: there are no APM selectors in `arch/desc.c`, and kernel faults are fatal. Instead:
   - connect the **real-mode interface** (INT 15h AX=5301h) and make every APM call through the existing BIOS VM (V86) broker;
   - admit only the APM function allowlist 5300h–530Fh plus 5380h OEM queries;
   - apply a per-call deadline;
   - on a fault or timeout, disconnect and treat APM as unavailable.

   Event polling once per second goes through the same path; measure and record its cost in microseconds per call on the host model.
2. **Quiescence.** Add a bounded `storage_sync` variant with a caller deadline, used by the critical-suspend and low-battery path. Flush, quiesce DMA and acknowledge within the budget; on expiry, record and acknowledge anyway, because a critical suspend cannot be refused.
3. **Power-source interface.** Implement APM behind a small kernel power-source provider interface: AC state, battery percentage and life, events, soft-off. f1-110 (ACPI) implements the same interface in parallel. Write its header as `src/kernel/include/ciuki/power_source.h` with ACPI and APM as two providers, exactly one active, and the lead reconciles at merge. The tray and Power page come from f1-110.
4. **Soft-off** uses APM Set Power State (5307h, all devices, off) after the orderly shutdown path.
