## Required

1. **Classes and windows.** `RegisterClass(Ex)`/`GetClassInfo(Ex)`/`UnregisterClass` with class atoms from `w32srv`, class and window extra bytes, `CreateWindowEx` for top-level, owned, child and popup windows with the styles the contract lists (overlapped, popup, tool, topmost, child, clip-children/siblings), `WS_EX_*` subset of the census, `DefWindowProc` for non-client behaviour (caption, close, minimise/restore, move/size through the frame are the desktop's: map them to protocol v3 placement and `WM_CLOSE`/`WM_ACTIVATE`/`WM_SIZE`/`WM_MOVE`/`WM_SHOWWINDOW`), `ShowWindow`, `SetWindowPos`/`MoveWindow`/`Get/SetWindowLong`/`Get/SetWindowText` (UTF-8 title to the desktop, ANSI 1252 to the program), `EnumWindows`/`EnumChildWindows`/`FindWindow`/`GetParent`/`SetParent`/`GetWindow`, z-order and owner rules, destruction order (`WM_DESTROY` children first, `WM_NCDESTROY`, timers and properties released), window properties (`SetProp`). Every top-level window = one protocol v3 window; child windows live in the parent's surface.
2. **Messages.** Per-thread queues on the f5-04 kernel queues: `PostMessage`, `SendMessage` (same-thread direct call; cross-thread with reply token and nested-send dispatch while waiting; `SendMessageTimeout`, `SendNotifyMessage`, `ReplyMessage`, `InSendMessage`), `PeekMessage`/`GetMessage` ordering per Windows (sent messages first, then posted, then input, `WM_PAINT` and `WM_TIMER` last, `WM_QUIT` handling), filters by window and range, `PM_NOREMOVE`, `TranslateMessage` (`WM_CHAR` from TEXT events, 1252), `DispatchMessage`, `MsgWaitForMultipleObjects(Ex)` with `QS_*` wake masks, `GetQueueStatus`, `WaitMessage`, `GetMessageTime/Pos`, `WM_TIMER` from `SetTimer`/`KillTimer` (callback and message forms, coalesced like Windows), `GetTickCount` consistency. Cross-process pointer messages: only the contract's allowlist (`WM_COPYDATA`, `WM_GETTEXT`/`WM_SETTEXT`, `WM_GETMINMAXINFO`…), copied payloads; everything else fails as Windows 9x did.
3. **Input and focus.** Keyboard and mouse messages built from protocol v3 KEY/TEXT/MOTION/BUTTON events exactly as the "Input" section specifies (lParam scan code, E0 bit 24, repeat and transition bits; VK codes from the active layout; `MapVirtualKey`, `VkKeyScan`, `ToAscii`, `GetKeyboardLayout`, `GetKeyState`/`GetAsyncKeyState`/`GetKeyboardState` with clearing on focus loss and RESYNC), mouse messages with client/screen coordinates, double-click synthesis (`GetDoubleClickTime`), `SetCapture`/`ReleaseCapture`, `SetFocus`/`GetFocus`/`SetActiveWindow`/`GetForegroundWindow`/`SetForegroundWindow` (activation from the desktop's focus events; the program's own requests follow Windows 98 rules, no foreground lock), `WM_ACTIVATE`/`WM_ACTIVATEAPP`/`WM_SETFOCUS`/`WM_KILLFOCUS`/`WM_NCACTIVATE`, `ClipCursor`, `SetCursorPos`/`GetCursorPos`, `ShowCursor` counts, `SetCursor`/`LoadCursor`/`CreateCursor`/`DestroyCursor` with shapes sent through v3 (cached by id), icons (`LoadIcon`, `CreateIconIndirect`, `DrawIcon(Ex)` via the f5-10B surface interface), `WindowFromPoint`, `ScreenToClient`/`ClientToScreen`, `GetWindowRect`/`GetClientRect`, `AdjustWindowRect(Ex)` with the desktop's frame metrics. Hooks: `WH_KEYBOARD`, `WH_MOUSE`, `WH_GETMESSAGE`, `WH_CALLWNDPROC`, `WH_MSGFILTER` same-thread only (the census set); others fail.
4. **Painting pipeline.** Update regions per window (`InvalidateRect`/`InvalidateRgn`/`ValidateRect`, `GetUpdateRect/Rgn`, `WM_PAINT` generation when the queue is otherwise idle, `WM_ERASEBKGND` with class brush, `BeginPaint`/`EndPaint` producing a clipped `HDC` from f5-10B on the top-level surface, `UpdateWindow`, `RedrawWindow`, `GetDC`/`GetWindowDC`/`ReleaseDC` with the clip to visible children/siblings, `ScrollWindow(Ex)`, `LockWindowUpdate` no-op); damaged rectangles only are sent to the desktop, coalesced per frame at the v3 pacing of f5-09; `WM_SETREDRAW`, `WM_SIZE` with the contract's minimise/restore semantics, `WM_SYSCOMMAND` subset.
5. **Clipboard, metrics, parameters.** Text (`CF_TEXT`, `CF_OEMTEXT`, `CF_UNICODETEXT` converted) and `CF_DIB`/`CF_BITMAP` clipboard through `w32srv` (global ownership, `WM_DRAWCLIPBOARD` chain, `WM_DESTROYCLIPBOARD`), `GetSystemMetrics` and `SystemParametersInfo` values of Windows 98 SE at the desktop's resolution and the contract's non-client sizes, `GetSysColor`/`SetSysColors` (the Windows 98 default scheme; the desktop theme is not exposed), `MessageBeep` to the f5-12 beep hook (stub until f5-12), `ExitWindowsEx` to the contract's end-session rule (f5-07B owns the full flow: return `TRUE` and record), `w-stubs` for the named Unicode exports.
6. **Evidence.** Host tests on the Linux adapter (f5-05): production message traces for nested cross-thread sends, modal loops with `PeekMessage` filters, new-input/timer/paint ordering, `WM_QUIT`, capture and focus transitions, destruction order; a replayed protocol v3 session (recorded events → messages) for both layouts (US and Italian tables pinned); painting pipeline tests with pinned damage rectangles; cross-process pointer rejection; the `user32` census coverage = 100 % implemented or W21 stub, with the per-export table in the report; `make CAP= apps`, `python3 -B -m unittest discover -s tests/host/win32 -t .`, `ASAN_OPTIONS=detect_leaks=0 bash scripts/test/host_kernel_tests.sh` if a kernel file changed, `python3 scripts/gen_api_reference.py` if a public header changed.
