5. **Runner:** the `installers` tier runs the ten cases from the lead's workload store at `build/downloads/win32/<id>/` copied into the per-run overlay (never into the image), one QEMU at a time; the suite skips with an exact reason when a payload is absent; Win16 engines (Worms) are reported `deferred (Win16)`.
6. Host tests for every piece that does not need QEMU (operator script parser, selector/loader registration, manifest comparison, payload staging); the lead runs the QEMU tier.
