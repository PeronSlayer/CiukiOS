## Required

1. **Per-process mixer.** One `/dev/audio` stream opened on first use at S16LE stereo 44,100 Hz (22,050 or 48,000 Hz when every source uses it; document the rule), one personality thread at `interactive` class mixing DirectSound secondaries, waveOut queues and the synthesizer with saturation, ≤ 2 quanta (256 frames) queued beyond the consumed counter, play cursors derived from `AUDIO_GET_STATUS`, stream gain for `waveOutSetVolume`/mixer wave-volume (never the master), `DSERR_ALLOCATED`/`MMSYSERR_ALLOCATED` when the kernel refuses (eight streams, `ENOMEM`), stream release on exit; a frozen internal interface (source registry, cursor model, callback quota) that f5-12B consumes.
2. **DirectSound.** `DirectSoundCreate(8)`, `DirectSoundEnumerate(A/W)` (one device "CiukiOS audio"), `IDirectSound`/`IDirectSound8` (`SetCooperativeLevel` all levels accepted, `GetCaps`, `GetSpeakerConfig`/`SetSpeakerConfig`, `Compact`, `Initialize`), primary buffer (`SetFormat` accepted within 4,000–48,000 Hz 8/16-bit mono/stereo; `DSBCAPS_PRIMARYBUFFER` with `Lock` writing into the mix as Windows 98 did only when `DSSCL_WRITEPRIMARY`; otherwise `DSERR_INVALIDCALL`), static and streaming secondary buffers (`DSBCAPS_STATIC`, `CTRLVOLUME/PAN/FREQUENCY/POSITIONNOTIFY/3D`, `GLOBALFOCUS`, `STICKYFOCUS`, `GETCURRENTPOSITION2`, `LOCSOFTWARE`), `Lock`/`Unlock` with wrap-around (two pointers), `Play` with `DSBPLAY_LOOPING`, `Stop`, `SetCurrentPosition`, `GetCurrentPosition` within one quantum (5.3 ms) of the consumed position with the documented write-cursor lead, `GetStatus`, `SetVolume` (hundredths of dB, table pinned), `SetPan`, `SetFrequency` (resampling, linear interpolation; document), `DuplicateSoundBuffer` (shared sample memory), `Restore` (no loss on this device: always `DS_OK`), `IDirectSoundNotify` (`SetNotificationPositions`, `DSBPN_OFFSETSTOP`, events signalled on the mixer thread with the documented order), `IDirectSound3DListener`/`IDirectSound3DBuffer` reduced to distance attenuation and pan per the contract (`DS3DMODE_*`, min/max distance, rolloff, deferred settings with `CommitDeferredSettings`), focus loss (`DSBSTATUS_BUFFERLOST` never; inactive windows mute non-`GLOBALFOCUS` buffers as Windows did, driven by f5-10A's activation), capture interfaces fail with `DSERR_NODRIVER`, `IKsPropertySet` queries fail cleanly.
3. **winmm.** `waveOutGetNumDevs`/`GetDevCaps`/`Open` (callback window, function, event, thread; `WAVE_FORMAT_QUERY`; PCM 8/16-bit mono/stereo 4,000–48,000 Hz, else `WAVERR_BADFORMAT`), `Prepare/UnprepareHeader`, `Write` with queued headers and `WHDR_DONE`/`MM_WOM_DONE` order, `Reset`, `Pause`/`Restart`, `BreakLoop`, `GetPosition` (bytes, samples, ms), `GetVolume`/`SetVolume` (stream gain), `GetPitch`/`GetPlaybackRate` (`MMSYSERR_NOTSUPPORTED`), `waveOutMessage`, `timeGetTime` (monotonic ms, wraps like Windows), `timeGetDevCaps` (1 ms), `timeBeginPeriod`/`timeEndPeriod` (accepted), `timeSetEvent`/`timeKillEvent` (one-shot and periodic on a personality thread at `interactive`, ≤ 16 per process, `TIME_CALLBACK_FUNCTION/EVENT_SET/EVENT_PULSE`, documented jitter), `timeGetSystemTime`, `mixerGetNumDevs` (1), `mixerOpen`/`Close`, `mixerGetLineInfo`/`GetLineControls`/`GetControlDetails`/`SetControlDetails` for the master (read-only mirror of the desktop's value, writes accepted and ignored with a record) and wave lines (stream gain), `mixerMessage`, `auxGetNumDevs` (0), `joyGetNumDevs` (16) with `joyGetPos`/`joyGetPosEx` → `JOYERR_UNPLUGGED`, `joyGetDevCaps` for the first device, `midiOutGetNumDevs` (1), `midiOutGetDevCaps` (the synthesizer, `MOD_SYNTH`, GM), `midiOutOpen`/`Close`/`ShortMsg`/`LongMsg` (sysex: GM reset and master volume only), `midiOutReset`, `midiOutSetVolume`, `midiStreamOpen`/`Out`/`Restart`/`Pause`/`Stop`/`Property` (tempo and time division) with `MOM_DONE` callbacks (the sequencer MCI of f5-12B uses it), `waveIn*`/`midiIn*` → no devices, `PlaySound`/`sndPlaySound` (WAV from file or resource, `SND_ASYNC/LOOP/NOSTOP/PURGE/MEMORY/RESOURCE`), `mmioOpen`/`Read`/`Seek`/`Descend`/`Ascend`/`Close` and the `mmio*` set the census lists, `mciSendString`/`mciSendCommand` entry points reserved for f5-12B (`MCIERR_DEVICE_NOT_INSTALLED` until then).
4. **MIDI synthesis.** One synthesizer instance per process, 16 channels, GM program/bank select, controllers (volume, expression, pan, sustain, modulation, pitch bend with range RPN, all-notes-off, reset), voices limited (64, stealing policy documented), rendered at the stream rate and mixed like any source, bank selection at process start from the installed RAM (full FluidR3 where RAM allows safely per the contract's refinement, the reduced bank ≤ 32 MiB at 128 MiB; the rule and the record format pinned), bank loaded once per boot into a shared read-only mapping (f5-04 sections) so processes share it, bounded decoded-sample cache, CPU measured per voice on the host with the F4 cost model and the Pentium III extrapolation documented.
