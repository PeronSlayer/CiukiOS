# f5-19b — the Win16 host runtime: ABI header (wave 0), selector manager, NE instantiation, heaps and thunk tables (wave 1, three worktrees), kernel 16-bit execution context and launch classification (wave 1, kernel lanes), integration (wave 2)

- **Phase:** F5 (Win16). **Model:** Claude Opus agents, one per lane (Codex out of credit until 2026-10-25). **Worktrees:** `wt/f5-19b-abi` (wave 0), `wt/f5-19b-sel`, `wt/f5-19b-ldr`, `wt/f5-19b-heap-thunk`, `wt/f5-19b-kernel`, `wt/f5-19b-launch` (wave 1), `wt/f5-19b-int` (wave 2), all from main after wave 0 is merged.
- **Contract:** `docs/design/win16-subsystem-contract.md`: §1–§9 (f5-19), the f5-19a delivery (NE parser with 54 named refusals, 118 fixtures, census), section P (f5-19P dispositions C01, C02, G01, G02, G04, G07, accepted 2026-10-20) and its plan P9; the lead's decisions in `docs/directives/f5-19p-win16-p0-dispositions.md` (INT 21h backend = the kernel's VMM DOS file API of f3-48…f3-51; versions GetVersion 3.95 / DOS 7.10 / INT 2Fh 1600h 4.10 to confirm from the Windows 98 Resource Kit in `build/rskt/` or the SDK before freezing; x87 emulator fixups recorded and patched to native x87 on first execution; the 32-threads-per-process limit enforced; operations 10Fh and 110h reserved). Owner decision 2026-10-20 (dev diary 2026-10-20-03): 32-bit segments, Win386, `WINMEM32.DLL` and thunks are a later step f5-19e; in f5-19b they stay named refusals.
- **Authority by lane:** wave 0: `sdk/win16/rt/abi16.h` only (runtime types: selector-manager and RUN backend interfaces, real and mock; task and token; arena; callback level; stub-table and typed-thunk record formats; P4's tables; the P1 kernel record header). Wave 1 `sel`: the selector manager (`sdk/win16/rt/`); `ldr`: NE module instantiation over the selector manager; `heap-thunk`: global and local heaps, atom and resource tables, stub/thunk tables; `kernel`: `src/kernel/proc/win32/` and `src/kernel/proc/` for operations 10Fh (per-host LDT) and 110h (blocking RUN returning every fault/INT to the flat caller), the Win16 record header, the 32-thread limit (f5-03 amendment, `docs/design/execution-abi.md` table); `launch`: NE recognition at the single process-creation entry (f5-05B/f5-06), host creation, the group ledger and reservation (P6/G07), the user32 wait hook at P2's two call sites. Wave 2 `int`: tasks and token, the RUN event loop with stub dispatch, InitTask/InitApp/WaitEvent, LibEntry/WEP order, Catch/Throw and escape propagation, the self-loader, P3's adapters (arena, per-task DOS state, INT 21h over the VMM DOS file API, INT 31h), WinExec/LoadModule/INT 21h 4Bh routing (NE inside the host, PE through f5-05/f5-06), the x87 patch, the version identity.
- **Not yours:** USER/GDI message conversion (f5-19c, P5), containment enforcement beyond the ledger (f5-19d), 32-bit segments (f5-19e), the DOS file API itself (f3), the kernel objects (f5-04).

## Required

1. **Wave 0.** `abi16.h` as P9 describes, frozen before any lane codes against it; a header-only host test that compiles it in the kernel, runtime and mock configurations and checks every record size and offset against the P4 tables.
2. **Wave 1, `sel`.** Selector allocation and release, huge runs with `__AHINCR` 8 and the remaining-size limits, aliases, `AllocDStoCSAlias`, `PrestoChangoSelector`, `Get/SetSelectorBase/Limit`, accounting per host (at most 1,024 LDT entries, the F3 LDT size), the real backend over operation 10Fh and the mock backend with identical behaviour; property tests on the mock.
3. **Wave 1, `ldr`.** Module table and use counts; segment allocation and loading over the selector manager; relocation binding (every f5-19a relocation kind, the Watcom codes named in the f5-19a open items); prolog patching per P4; entry lookup including constant entries; the 54 refusals of f5-19a preserved; fixtures: f5-19a's 118 plus authored ones for every new path.
4. **Wave 1, `heap-thunk`.** Global heap (fixed and movable handles, a movable handle being its selector − 1, lock and discard semantics per C03), local heap, atom tables, resource tables, the stub tables for both call directions and the typed thunk records of P4; budget accounting per host.
5. **Wave 1, `kernel`.** Operation 10Fh: one LDT per Win16 host, 16-bit descriptors only, re-checked before every return to 16-bit code; operation 110h: the blocking RUN call returning every 16-bit fault, `INT n` and INT 80h as an event to the flat caller (the vm86(2) shape of C01), no per-callback kernel state; the Win16 record header; the 32-threads-per-process limit; host tests on the production code with the validator shared with the mock; the i686 build.
6. **Wave 1, `launch`.** NE classification at process creation (MZ/NE, Windows targets; PE/LE/LX/OS2/DOS refusals as f5-19a names them), host creation by the kernel, the group ledger fixed at launch (helpers marked attached die with the host; normal exit kills nothing), refusal by name of an NE launched by a 32-bit group member, policy limits, the Win16 crash record; the user32 wait hook at P2's two call sites with the lock-order test.
7. **Wave 2, `int`.** Everything P9 lists for the integration owner, built on the merged lanes; host gates: the full life of the authored fixtures on the mock RUN backend (entry registers, InitTask, LibEntry, API calls, WEP, 4Ch), a Catch/Throw escape through a nested 16→32→16 callback, the self-loader fixture and malformed headers, the INT 21h rows against f3-48's expectations through the VMM DOS file API, the INT 31h matrix, INT 80h events refused, the x87 patch fixture, the version identity confirmed and recorded with its source.
8. **Evidence per lane.** The lane's own host tests plus `scripts/test/host_kernel_tests.sh` (kernel lane), `make CAP= apps` where apps change, `python3 -B -m unittest discover -s tests/host/win32 -t .` (launch and int lanes), `python3 scripts/gen_api_reference.py --check` where the ABI table changes. Reports `build/codex/f5-19b-<lane>-report.md`. The lead's first execution milestone stays f5-19r's: a normal-CRT EXE and DLL and a 16→32→16 callback on the canonical image, QEMU case written by the `int` lane and run by the lead.
