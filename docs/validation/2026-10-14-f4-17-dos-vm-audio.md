# F4-17 DOS VM playback and level diagnostics

Research checked before implementation, 2026-10-14. Physical qualification
of DOOM and Wolf3D on the T23 belongs to the lead; no QEMU is run here.

## Sources and implementation decision

- [Creative Sound Blaster Series Hardware Programming Guide](https://pdos.csail.mit.edu/6.828/2005/readings/hardware/SoundBlaster.pdf),
  sections 3-6, 3-28 and commands Cxh, D0h/D4h, D5h/D6h: C6h is **8-bit**
  auto-init output with FIFO, B6h is 16-bit output. D0h pauses 8-bit DMA
  requests; D4h resumes them. Switching a running auto-init transfer to a
  single-cycle command is deferred to the block boundary. The repository
  incorrectly deferred fresh auto-init commands too, including behind a
  paused transfer that cannot reach that boundary. Restrict this deferral
  to single-cycle commands and start a fresh auto-init transfer immediately.
  Keep single-cycle tail deferral, width-specific pause and IRQ semantics.
- [DOSBox Staging upstream soundblaster.cpp](https://github.com/dosbox-staging/dosbox-staging/blob/main/src/hardware/audio/soundblaster.cpp),
  `dsp_prepare_dma_new`, `dsp_do_dma_transfer`, D0h/D4h handling: new DMA
  setup replaces the DMA mode and establishes a new transfer, including
  after a pause. Used for behavior comparison only; no code copied.
- [Intel 8237A datasheet 231466-005 (mirror)](https://studylib.net/doc/8146290/8237a-high-performance-programmable-dma-controller),
  autoinitialize, mask register and mode register: 59h selects channel 1,
  memory-to-device read, single-transfer arbitration, auto-init. 58h selects
  channel 0, not channel 1. Current/base address/count and the shared byte
  flip-flop in the production DMA model already match this programming.
  A mask/disabled controller waits; a wrong transfer type or inaccessible
  guest address fails locally. Do not unmask DMA or resume a DSP pause on
  the guest's behalf.
- Creative guide chapters 4 and 6: CT1745 master/voice/FM attenuation is
  independent of DSP pause. D1h/D3h have no DAC gating effect on DSP 4.xx,
  and speaker control does not gate FM. Preserve the documented gains;
  measure source and final digital levels instead of boosting them blindly.

## Evidence limits and diagnostic contract

The supplied T23 log's `halt=1` is `audio.halts`, a cumulative **physical
transport** counter. It is not `dosvm_sb_transfer.paused` or a virtual DMA
failure. Likewise `fm` counts nonzero frames after CT1745/source gains,
not all frames synthesized. Growing `fm` proves nonzero source output,
but does not establish its level or final publication. The log does not
contain DSP commands, DMA mode/mask, guest IRQ services or PCM values;
the exact hardware failure cannot be assigned from it alone.

Record SB state transitions in bounded storage without printing on guest
I/O, timer, IRQ or refill paths. Emit from the existing VM worker, with
physical IF enabled and outside the guest interrupt chain. Overflow is
counted explicitly. Keep periodic DMA/IRQ and gain/level snapshots reachable
even under continuous state traffic. Label the old physical counter
`backend_halts` and record current backend running state separately.

Level records describe one-second windows: PCM and FM after CT1745/source
gains, their combined contribution after the native digital master, and
the final published mixer ring (shared across native/VM sources). Values
are integer peak dBFS, with `-96` and peak zero denoting digital silence.
Codec master attenuation is reported separately when applied in hardware.
Reading diagnostics must not clear a window, change mute/gain, wake the
worker or consume guest audio. UI suppression via
`CIUKI_AUDIO_DIAG_VM_ACTIVE` remains an observation of VM activity; it does
not mute or halt the VM source.

## Host validation

Commands, regression controls and results are recorded in
`build/codex/f4-17-report.md`. The replay uses production DSP/DMA, VM source,
OPL synthesis and mixer code with synthetic guest RAM and a fake accepting
native transport. DMX is not included in id's published DOOM source: this is
a protocol replay, not execution of DMX or the commercial game.
