# Quake startup diagnostics and disk reads

Research checked on 2026-10-15 before implementation:

- [SeaBIOS disk services](https://github.com/coreboot/seabios/blob/master/src/disk.c)
  pass the validated sector count to the disk operation and report completed
  sectors. CiukiOS preflights the BIOS request but reads its backing file one
  sector at a time. `fat_read` starts at the file's first cluster on each
  call. Keep guest completion semantics and cache read-only backing bytes in
  two 64 KiB windows, so alternating FAT metadata and sequential data do not
  force a backing-file read for every sector. Check the private overlay first.
  Failed read-ahead must retry only the requested sector.
- [SeaBIOS VGA services](https://github.com/coreboot/seabios/blob/master/vgasrc/vgabios.c)
  obtain the active text page and cursor from the BIOS data area. Capture
  that page through CiukiOS's existing non-mutating guest-memory reader.
  Encode characters as hex in bounded guest records, preserving raw bytes.
  Report once at launch and every five seconds until graphics frames appear.
- [Quake DOS system code](https://github.com/id-Software/Quake/blob/master/WinQuake/sys_dos.c)
  queries DPMI memory and attempts to lock its allocation. The current window
  configuration enables the native DPMI host and commits 32 MiB, including a
  24 MiB shared pool. Keep these limits. The launcher already changes to
  `\QUAKE` before executing `QUAKE.EXE`; the probe launches RUNREC with that
  directory and hashes each package member once before execution.

The T23 evidence for image a738204a records 420 real-mode interrupts taking
494836 microseconds in its first interval. It has neither a vector histogram
nor post-boot screen text, so it cannot establish which vector caused that
cost. The 2048-byte `launch-image` maximum belongs to native executable
loading, before the guest workload. New cumulative vector records distinguish
interrupt dispatch from synthetic firmware service and include CPU time and
the slowest call's input AX. CPU accounting excludes task suspension.

The ASan/UBSan VM harness passed 8061658 checks, with a maximum record length
of 237 bytes. Its interleaved data/metadata workload reduced 256 backing
reads of 512 bytes to two reads of 65536 bytes. The clock fixture measured
3000 microseconds of BIOS service CPU time while excluding 9000 microseconds
of simulated task suspension. This validates accounting, not T23 latency.
Six focused workload/autorun tests and five i686 translation-unit checks
also passed. No image was built and no QEMU run was performed.

Read-only inspection of the existing main image, SHA-256
`5ff88a8a5414e440dd68b997737ed20d1c3b23ae508911c57373c1eae788feb4`,
verified all sixteen pinned package members inside its embedded games disk,
including `QUAKE.EXE` and `ID1\PAK0.PAK`, plus AUTOEXEC and RUNREC. Its
manifest names revision `56d41c09`, matching the directive. The acquisition
directory contains logs only; that directory's label cannot establish the
physical image's SHA-256.

Verbose startup diagnostics work without a selected probe. Screen records
have `src=screen`, a snapshot number `n`, zero-based `row`, one-based `part`
and `parts`, and hex `data`. Blank trailing cells and empty rows are omitted;
the header identifies mode, dimensions and read error. Each full 80-column
row needs at most two records. Graphics modes emit only the header. Records
are deferred until a guest hardware interrupt has returned; stopped workers
also capture a final screen. Quiet boots retain their existing record policy.

`vm_perf_v` counters are cumulative per VM generation and snapshot number.
`path=int` measures dispatch, including INT FEh; `path=bios` identifies the
effective ROM service, such as vector 13h. These overlapping totals must not
be added. `us` and `max_us` exclude task suspension; `ax` is the input AX of
the slowest invocation. `vm_perf_disk` reports backing-file request counts,
bytes, maximum requested size and base-cache hits. The cache adds 128 KiB per
VM within the existing low-memory budget; guest memory quotas stay unchanged.
