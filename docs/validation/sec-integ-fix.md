# Security integration: F2 app-gate host model

The sec-integ-fix directive identifies three host regressions after sec-k01 and
sec-k02 integration. Inspection confirms that these are test-model defects.

Sources checked before the change:

- Microsoft [Access tokens](https://learn.microsoft.com/en-us/windows/win32/secauthz/access-tokens)
  binds authorization to a process/thread security context.
- Microsoft [CSIDL](https://learn.microsoft.com/en-us/windows/win32/shell/csidl)
  distinguishes a user's profile, documents and application-data directories.
- Microsoft [Gaming with Least-Privileged User Accounts](https://learn.microsoft.com/en-us/windows/win32/dxtecharts/gaming-with-least-privileged-user-accounts)
  describes writable personal data locations and protected system/program paths
  on XP NTFS. CiukiOS's FAT32 enforcement remains its explicit kernel policy.

The governing local contract is `docs/design/user-security-contract.md`, section
8.2/A1-10. Its authenticated user environment is generated by
`credential_environment()` in `proc/spawn.c`, with protected profile paths,
LC_ALL, validated TZ and fixed PATH. The F2 Lua gate instead calls
`supervisor_spawn_gate()` -> `supervisor_spawn()` -> `spawn_process()` as a
supervisor test payload. Its five generated variables still match the gate's
metadata; it is not an authenticated desktop/session-launch adapter. Keep this
test scoped to that path. Its extracted pre-ELF harness must consume the new
`role` parameter, whose production use occurs after the extraction boundary.

Sec-k02 adds a 40-byte `policy_label` to `px_node` on this host. The resulting
1040-byte node plus the eight-byte heap header requires the 2048-byte class,
instead of the old 1024-byte class. Production `gate_identity_size()` already
computes this from `sizeof(px_node)`; production `kheap.c` charges the same
power-of-two class. The host fake uses that production helper too. Update the
exact Python assertions to 2048 bytes per added identity, 122880 bytes for 60
identities, and 3072 final heap bytes (1024 baseline plus one identity). Retain
the zero-remainder assertions and negative controls for unattributed growth.

No production allocation, attribution, launch environment, ABI or SDK change is
required for these failures. Host verification and any later-suite failures are
recorded in `build/codex/sec-integ-report.md`; guest execution is outside this
directive's implementation validation.
