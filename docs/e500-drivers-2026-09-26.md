# Armada E500 hardware and driver investigation — 2026-09-26

The reported machine boots to an 800×600 desktop but neither keyboard nor
pointing device responds. This is not evidence that Windows input drivers are
missing. Compaq documents an i8042-compatible host interface for both devices;
the native controller initialization and its failure recovery require review.

## Hardware evidence

Compaq's original *Armada E500/V300 Technical Reference Guide*, chapter 5,
describes the internal 8051 controller, its firmware-owned peripherals, and
keyboard/mouse access through ports 60h and 64h. Chapter 6 identifies ESS
Maestro-2E audio with an ES1921 AC97 codec. Chapter 7 describes ATI Rage
Mobility-P, panel variants and VBE/DDC-era display capabilities.
[Original Compaq manual, mirrored transcription](https://manualzz.com/doc/48555918/compaq-armada-v300-series-reference-manual).

Oracle's E500 hardware compatibility submission contains an actual PCI listing:
video `1002:4C4D`, subsystem `0E11:B160`; audio `125D:1978`, subsystem
`0E11:B112`; Intel 440BX/PIIX4; Intel PRO/100 `8086:1229`; UHCI USB
`8086:7112`; TI CardBus `104C:AC1C`. These identify that configuration, not
every optional modem/NIC fitted to every E500.
[Oracle/Sun E500 HCL record](https://www.oracle.com/ocom/groups/public/@otn/documents/webcontent/373933.html).

The Linux upstream driver independently identifies `125D:1978` as Maestro-2E
and uses Maestro-specific registers. An AC97 **codec** does not imply the
Intel ICH **controller** register/DMA layout.
[Linux v6.12 es1968.c](https://raw.githubusercontent.com/torvalds/linux/v6.12/sound/pci/es1968.c).

## Included generic DOS mouse driver

CuteMouse 2.1b4 supports PS/2 and serial mice and is GPL-licensed. The official
FreeDOS 1.4 archive was downloaded; complete source and licensing are retained.
The separately maintained Linux/JWasm port by Davide Bresolin was also pinned
and compiled with the existing local JWasm 2.21. The integrated `INPUTINI.COM`
tries it only after failed native initialization has released the mouse IRQ
owner; it is never stacked over working CiukiOS input.
[Official FreeDOS package](https://www.ibiblio.org/pub/micro/pc-stuff/freedos/files/repositories/1.4/base/ctmouse.zip),
[published port](https://github.com/davidebreso/ctmouse).

[HP SP18571 description](https://ftp.hp.com/pub/softpaq/sp18501-19000/sp18571.txt),
[HP SP18571 executable](https://ftp.hp.com/pub/softpaq/sp18501-19000/sp18571.exe),
[HP SP11684 description](https://ftp.hp.com/pub/softpaq/sp11501-12000/sp11684.txt),
[HP SP11684 executable](https://ftp.hp.com/pub/softpaq/sp11501-12000/sp11684.exe).

The newer archive contains VxDs, Win16 support DRVs and a Windows installer;
it does **not** contain `MAESTRO.COM`. The older package contains a multi-disk
InstallShield cabinet set, not a directly usable DOS initializer in its outer
archive. Neither package has been executed or installed.

The text descriptions permit electronic distribution, while the embedded
SoftPaq license limits copying/distribution to one site and preserves existing
component agreements. A broadly redistributable CiukiOS runtime package cannot
treat those files as public domain or GPL. These downloads remain in
`build/full/e500-driver-research-2026-09-26` for inspection; they are not silently
added to the OS or presented as CiukiOS kernel drivers.

The shipped VSBHDA 2.0 source has no ESS1978 backend. Upstream SBEMU lists ESS
Allegro-1 ES1988/ES1989, which is a different controller family. Therefore the
detector reports Maestro-2E as unsupported PCI audio with a legacy Sound
Blaster fallback; it never selects Intel ICH or Allegro code for ESS1978.
[VSBHDA's supported-controller list](https://github.com/Baron-von-Riedesel/VSBHDA/blob/main/vsbhda.txt),
[SBEMU's supported-controller list](https://github.com/crazii/SBEMU/blob/master/README.md).

No BIOS/firmware update, physical disk modification or optical-disc write was
performed by this investigation. Compile/static checks do not establish that
the E500's keyboard, mouse or audio now work on the physical machine.
