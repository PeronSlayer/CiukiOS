Radeon MMIO 2D port for CiukiOS

Linux v6.12: drivers/video/fbdev/aty/radeon_accel.c, radeonfb.h,
radeon_base.c (engine/PCI table reference), include/video/radeon.h.
Upstream: https://github.com/torvalds/linux/tree/v6.12
The imported engine fragments and register definitions carry GPL-2.0.
The kernel GPL version 2 text is in the repository LICENSE.
The original acceleration code credits the XFree86 ACCEL_MMIO branches (--dte).
No Linux OS compatibility layer or full fbdev driver is imported.

X.Org ATI xf86-video-ati-6.14.6: src/radeon_cursor.c, radeon_accelfuncs.c
and radeon_reg.h.
Upstream: https://gitlab.freedesktop.org/xorg/driver/xf86-video-ati
Readable pinned mirror: https://github.com/freedesktop-unofficial-mirror/xorg__driver__xf86-video-ati/tree/xf86-video-ati-6.14.6/src
Cursor control/locking sequence adapted with native Ciuki monochrome payload.
MMIO Mono8x8PatternFill and ScanlineImageWrite/SubsequentScanline sequences
adapted for synchronous bounded packets and the part A native-format hook.
Authors: Kevin E. Martin, Rickard E. Faith, Alan Hourihane, Michel Daenzer.
Original credits thank Ani Joshi for Radeon initialization source.
