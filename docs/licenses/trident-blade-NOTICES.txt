Adaptation is in src/kernel/drivers/video/trident/engine.c. Only Blade and
XP local-framebuffer initialization, fill and copy sequences are ported.
Ciuki lifecycle, ownership, transport, deadlines, quarantine, pixel checks,
tests and byte-pitch correction are new glue. No donor .c file is included.
Linux mode setting, Image/TGUI, host expansion and silent reset are excluded.
The original source notice and origin remain in engine.c.

GPL version 2 text: CiukiOS repository LICENSE; installed alongside this
notice as trident-blade-GPL-2.0.txt. Source is supplied in the CiukiOS source
tree. X.Org files cited in docs/design/trident-blade-2d.md are register
cross-check references; their implementation is not imported.
