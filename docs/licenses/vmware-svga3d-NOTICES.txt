VMware SVGA3D protocol values (f7-31 SVGA3D backend)
Origin: VMware SVGA3D device headers as distributed in
  Mesa 21.3.9 src/gallium/drivers/svga/include/ (MIT, below) and
  Linux v6.1 drivers/gpu/drm/vmwgfx/device_include/ (GPL-2.0 OR MIT).
Pins, URLs and SHA-256: docs/design/f7-family-vmware-svga3d.md section 1.
Used at src/kernel/drivers/video/vmwaresvga/vmwaresvga3d_protocol.h: numeric
command ids, enumerators, devcap indices and capability bits only, each with
its source line. No upstream header or .c file is included or compiled; the
backend, owner and host model are original GPL-2.0-only code.
Mesa svga, the Linux vmwgfx driver, VirtualBox (GPL-3.0) and QEMU sources
were read as references for semantics and host behaviour, not imported.
The precision envelope header is a CiukiOS file copied from the Savage
backend (src/kernel/drivers/video/s3savage/savage3d_precision.h).
