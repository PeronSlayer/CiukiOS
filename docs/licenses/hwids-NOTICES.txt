The original snapshot files remain local, ignored inputs in build/downloads.
The installed JSON files contain selected, sanitized ID/name pairs only.
The generator is scripts/build_hwids.py; selection is documented in
assets/hwids/README.md and assets/hwids/retro-scope.json in the source tree.
Upstream names fill gaps after INF-derived names and native reference labels.
The owner's Windows INF collection and all driver binaries remain external;
they are neither copied into the repository nor distributed in the image.
