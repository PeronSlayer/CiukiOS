Imported/ported closure:
- src/add-ons/accelerants/3dfx/3dfx.h -> registers.h
- src/add-ons/accelerants/3dfx/3dfx_draw.cpp -> engine.c
- src/add-ons/accelerants/3dfx/3dfx_cursor.cpp -> engine.c
- src/add-ons/accelerants/3dfx/3dfx_init.cpp -> engine.c (read-only sizing)
- src/add-ons/accelerants/3dfx/3dfx_mode.cpp -> engine.c (FIFO/idle fence only)
- src/add-ons/kernel/drivers/graphics/3dfx/driver.cpp -> driver.c (PCI/BAR)
All runtime files are under src/kernel/drivers/video/tdfx/.
Haiku engine.cpp and its Be Sample code are not imported.
Linux v6.12 include/video/tdfx.h and drivers/video/fbdev/tdfxfb.c, and
X.Org tdfxdefs.h at 278042ff4c469f24ab7bc28e517e8a78e2821ddc,
were read as corroborating register references, not imported implementations.
New OS glue, bounded waits, quarantine, leases and host fixtures: CiukiOS.
