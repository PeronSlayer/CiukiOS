CiukiOS NeoMagic native port (f2-121)

Linux v6.12 drivers/video/fbdev/neofb.c and include/video/neomagic.h:
https://github.com/torvalds/linux/tree/v6.12/drivers/video/fbdev
Engine fragments: Denis Oliver Kropp, 2001-2002; card-specific code based
on XFree86's NeoMagic driver. The CiukiOS port replaces Linux glue and
unbounded waits, preserves the upstream GPL notice, and uses GPL version 2
(the Linux tree COPYING and this repository LICENSE contain the terms).
