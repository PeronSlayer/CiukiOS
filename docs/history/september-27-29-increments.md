### 27–29 September increments (state at the time)

- Completed the three items the integration audit left open. QEMU only:
  - **Runtime negotiation of the V86 IF profile.** Jemm's new versioned `Host_Scheduler_Profile` service (query/request/release, virtual IRQ raise, IRQ1/12 filter, state, poll) replaces selection by build hash. There is one Jemm build. CVSESSION requests the profile when its scheduler is armed unless the owner declines (op 0Ah), and reports `VM_CAP_V86_VIRTUAL_IF`.
  - **Peripheral model connected to DOS programs.** CVSESSION device ops 30h–35h trap 60h/64h, ISA DMA, SB16 and OPL ports for V86 programs and raise model IRQs into the profile's single virtual PIC. Physical 8042 bytes are captured by focus, and PCM (SB DMA plus DBOPL, now built into CVSESSION with clang) is streamed to the ICH AC'97. DEVTEST and GUESTIO hear the SB square wave and the OPL note in the QEMU capture. Protected-mode (HDPMI) clients are not attached yet.
  - **Resizable DOS window with raw keyboard and mouse.** The VGA-session DOS window has a resize grip, and the guest is rescaled into any client from 320×200 to the desktop work area. Guest keys arrive as raw scan codes on virtual IRQ1 (INT 9/port 60h), and a virtual INT 33h mouse follows desktop focus. Close sends Esc through the model.

  Fixes found on the way:
  - lost virtual IRQ1 at session end, which left the physical 8042 full and the desktop keyboard/mouse dead;
  - extra model IRQ0s;
  - a poll that was too frequent;
  - a stale BIOS key reaching the desktop;
  - the launch scene painted to the hidden page (window frame and task button missing).

  See `docs/vm-input-audio-devices-2026-09-27.md`, `docs/vm-v86-interrupt-profile-2026-09-27.md` and `docs/validation/2026-09-27-devices/`.

VGA acceptance, the native DOS window and the earlier session gates also pass with the final module. Fixes along the way:

- Made the native desktop, Setup and VGASETUP fluid: every framebuffer access now goes through a shared backend (`vbe_fb.inc`) that uses the VBE 2.0 linear framebuffer through short interrupt-free protected-mode bursts (no unreal limit survives a burst; banked access remains the fallback for V86, missing A20 or firmware without LFB). - Added the pinned, source-audited VBESVGA Windows 3.1 stack with EDID-selected resolution, 16-bit colour, VDD/grabber components, a resident auxiliary INT 10h stack, and source-rebuilt helper utilities. `VGASETUP` now reports VBE/EDID capabilities, enumerates and tests modes, persists the Windows resolution/depth profile on writable installed media, accepts the safe LCD-native `AUTO/60` refresh policy, and controls the IBM ThinkPad brightness EC/NVRAM path without touching unknown hardware. Focused gates produce non-silent waveforms for Intel ICH AC'97, real/protected Sound Blaster, Doom-vanille OPL2+SB, Wolf3D OPL2+SB, and original Doom OPL2+speaker.
- Replaced bootstrap-only `INT 19h` reboot with a cold-reset cascade shared by the shell, installer, and runtime: Intel ICH `CF9`, 8042 `RESET#`, then a null-IDT triple fault. The hardware-control gate proves that the chipset reset reaches QEMU's system-reset path under `-no-reboot`.
- Rebuilt the Live-CD installer path for real PATA hardware. The standalone FORMAT action resolves its ATA target before writing, while INSTALL obtains the physical CD controller/device and boot-image LBA from the El Torito `AH=4Bh` packet and reads the image with direct ATAPI `READ(10)` instead of alternating BIOS CD calls with raw HDD writes. After a real ThinkPad T23 exposed an optical `CHECK CONDITION` at source sector 10048, reads were reduced to one native 2048-byte block and gained twelve same-block retries, CPU-independent retry pauses, ATAPI Error/sense-key diagnostics, and periodic selected-device `DEVICE RESET` recovery without channel-wide SRST. Polled IDE operations mask unsolicited IRQs and use bounded timeouts. Installation is transactional: sector zero is invalidated and flushed first, D: is patched to C: in-flight, every payload write is flushed, and the bootable MBR is committed last. Failure never reboots a partial target. Gates now inject a one-shot optical EIO at the observed sector and require recovery plus a full byte-for-byte clone, force a 5% interruption and prove the partial disk cannot boot, and require HDD-only startup from C:.
- Removed Windows 3.1's fixed per-program DOS memory ceilings: generated `_DEFAULT.PIF` and `DOSPRMPT.PIF` profiles now request all available conventional, EMS, and XMS memory, while DOSMGR-selected synthetic PSPs receive a generic conventional arena. Windows startup records its baseline EXEC depth and every later Win16/DOS-VM frame unwinds independently, preventing cumulative memory loss after Media Player or another child closes.
