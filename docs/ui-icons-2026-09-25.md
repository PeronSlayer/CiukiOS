# Official icons — 2026-09-25

CiukiOS now uses selected native 32×32 artwork from Tango Icon Theme 0.8.90.
The complete upstream archive, original Public Domain declaration, authors,
selected source PNGs and deterministic conversion manifest are preserved in
[`assets/icons`](../assets/icons/README.md). Computer and Install include the
approved Ciuki portrait; About uses that portrait directly. The existing header,
Setup and About-dialog portraits retain their approved pixels and colours.

The shell reads `\SYSTEM\UI\ICONS.DAT` once on entering the desktop. The
18,448-byte allocation is released before returning to DOS or running a child.
Drawing only reads the cached data; it performs no filesystem operations.
The loader checks the complete header, exact file size and all palette indices.
Missing or invalid resources leave the existing built-in icon path available.
The first 80 UI/portrait palette entries remain unchanged; Tango uses 64 new
entries. Planar VGA uses a bounded map to the existing 16 colours.

The normal build includes the resource and `CREDITS.TXT`, `TANGO.TXT` and
`AUTHORS.TXT` in `\SYSTEM\UI`. The graphical installer clones this directory
with the complete source volume. No kernel, disk-writing or EXEC routine was
changed for this icon integration.

## Validation

- `uv run --with unicorn python scripts/test_ui_icons.py`: 566 scenarios using
  the production assembly, covering loader errors, lifetime, all 18 sprites,
  transparency, packed/planar colours, bands, guards and register preservation.
  DOS services and the rectangle sink are simulated in this CPU test.
- `uv run --with unicorn python scripts/test_ui_palette.py --output
  build/full/retro-icons-2026-09-25/palette-cpu`: 15 cases across 16/80/144 palette
  entries and 8/15/16/24/32-bit destinations, including bounds and invalid calls.
- `python3 scripts/qemu_test_ui_icons.py --mode 800` and `--mode 2560`:
  real QEMU screenshots at 800×600 and 2560×1440, with 128 MiB RAM. All checked
  icon/portrait pixels match the native assets within the six-bit DAC tolerance.
  At 800×600 a maximize/restore cycle leaves zero changed stable pixels; Setup
  retains its correct portraits. Both modes execute COMDEMO from DOS and return
  to the desktop with correct icon pixels and working pointer recognition.
- Both isolated disk images contain byte-identical icon data and all three
  attribution files. Source disk hash is unchanged. Asset hash checks,
  assembly, build-script syntax and whitespace checks pass.
